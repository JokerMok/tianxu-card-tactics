# 横屏战术卡牌原型核心战斗规则文档

版本：v0.1  
日期：2026-06-29  
平台：手机横屏  
引擎：Unity 2D  
范围：历史 PVE 核心战斗原型

> 本文档中的三路六格、能量费用和冷却规则已失效。当前 R1.6 基线为 1v1 两路十二格、双方各自最近的 `2×3` 召唤区、准备值出牌与完整自动托管，详见《核心战斗规则文档-v1.6》。

## 1. 项目定位

本项目为横屏 2D 战术卡牌 PVE 游戏原型。

核心体验为：玩家通过抽牌、蓄能、部署单位和释放少量技能，影响三条横向路线上的自动推进战斗。单位上场后自动移动、自动攻击，玩家不直接控制单位移动和普通攻击。

第一版只验证战斗是否成立，不验证商业化、长期养成、社交和完整剧情。

## 2. 设计目标

### 2.1 核心目标

- 单局时长控制在 5 至 8 分钟。
- 玩家每回合至少有 1 个有效决策。
- 战斗主要压力来自路线选择、出牌时机、资源分配和技能干预。
- 单位自动推进，减少微操。
- PVE 关卡可通过敌方牌组、出牌策略和关卡规则形成差异。

### 2.2 非目标

- 不做 PVP。
- 不做实时操作战斗。
- 不做玩家手动控制单位移动。
- 不做原有游戏名称、卡牌名称、美术、剧情和数值复刻。
- 不做交易、拍卖、公会、充值和完整养成系统。
- 不做复杂随机地图。

## 3. 战斗概览

### 3.1 战斗视角

战斗采用手机横屏视角。

- 我方英雄位于左侧。
- 敌方英雄位于右侧。
- 中间为 3 条横向路线。
- 每条路线由 6 个战斗格组成。
- 单位从己方侧向敌方侧自动推进。

### 3.2 战场结构

| 项目 | 规则 |
|---|---|
| 路线数量 | 3 条 |
| 每路线格子 | 6 格 |
| 我方部署格 | 每条路线最左侧第 1 格 |
| 敌方部署格 | 每条路线最右侧第 6 格 |
| 我方推进方向 | 从左到右 |
| 敌方推进方向 | 从右到左 |
| 单格单位上限 | 每格最多 1 个单位；单位进入被占用格前停止 |

### 3.3 坐标定义

路线编号从上到下为 Lane 1、Lane 2、Lane 3。  
格子编号从我方到敌方为 Cell 1 至 Cell 6。

英雄位置使用虚拟格：

- 我方英雄：Cell 0
- 敌方英雄：Cell 7

我方部署位置为：

- Lane 1, Cell 1
- Lane 2, Cell 1
- Lane 3, Cell 1

敌方部署位置为：

- Lane 1, Cell 6
- Lane 2, Cell 6
- Lane 3, Cell 6

## 4. 对战双方

### 4.1 我方

我方由英雄、牌库、手牌、弃牌区、能量和场上单位组成。

### 4.2 敌方

敌方由敌方英雄、敌方牌库、敌方手牌、弃牌区、能量、场上单位和 AI 出牌策略组成。

第一版敌方不显示完整手牌，只显示敌方行动结果。

## 5. 胜负规则

### 5.1 胜利

敌方英雄生命值降至 0 时，我方胜利。

### 5.2 失败

我方英雄生命值降至 0 时，我方失败。

### 5.3 回合上限

第一版设置 30 回合上限。达到上限后根据双方英雄剩余生命判定：

- 我方英雄生命高于敌方英雄：胜利。
- 我方英雄生命低于或等于敌方英雄：失败。

该规则用于避免低压关卡拖入无效回合。

## 6. 回合流程

战斗采用回合制。每个完整回合包含我方阶段和敌方阶段。

### 6.1 我方阶段

1. 回合开始。
2. 结算回合开始效果。
3. 我方抽 1 张牌。
4. 我方能量恢复。
5. 我方可出牌。
6. 玩家点击结束回合。
7. 我方场上单位依次行动。
8. 结算回合结束效果。

### 6.2 敌方阶段

1. 敌方回合开始。
2. 结算敌方回合开始效果。
3. 敌方抽 1 张牌。
4. 敌方能量恢复。
5. 敌方 AI 出牌。
6. 敌方场上单位依次行动。
7. 结算敌方回合结束效果。

### 6.3 行动顺序

单位行动按路线和格子顺序执行。

我方单位行动顺序：

1. Lane 1 从右到左检查我方单位。
2. Lane 2 从右到左检查我方单位。
3. Lane 3 从右到左检查我方单位。

敌方单位行动顺序：

1. Lane 1 从左到右检查敌方单位。
2. Lane 2 从左到右检查敌方单位。
3. Lane 3 从左到右检查敌方单位。

靠近敌方英雄的单位优先行动，减少前排被后排阻塞造成的异常。

## 8. 牌库规则

### 8.1 牌组规模

第一版每副牌组为 20 张。

| 类型 | 数量 |
|---|---|
| 单位卡 | 16 张 |
| 技能卡 | 4 张 |

### 8.2 初始手牌

战斗开始时抽 4 张牌。

玩家可在战斗开始前进行一次换牌：

- 最多选择 2 张手牌放回牌库。
- 放回后重新抽取相同数量。
- 牌库重新洗牌。

第一版可先实现为自动保留，不做换牌界面。

### 8.3 抽牌

每方在自身回合开始时抽 1 张牌。

### 8.4 手牌上限

手牌上限为 6 张。抽牌后超过上限时，最右侧新增牌进入弃牌区。

### 8.5 牌库耗尽

牌库耗尽时，将弃牌区洗入牌库。若弃牌区也为空，则本次抽牌失败，不造成额外伤害。

第一版不使用疲劳伤害。

## 9. 卡牌类型

### 9.1 单位卡

单位卡用于在指定路线部署一个单位。

单位卡必须包含以下字段：

| 字段 | 说明 |
|---|---|
| CardId | 卡牌唯一编号 |
| Name | 原创卡牌名称 |
| Cost | 能量费用 |
| Cooldown | 使用后冷却回合数 |
| MaxHp | 最大生命 |
| Attack | 攻击力 |
| Range | 攻击距离 |
| Move | 移动距离 |
| Tags | 类型标签 |
| Skills | 被动或触发技能 |

### 9.2 技能卡

技能卡用于造成即时效果。

技能卡必须包含以下字段：

| 字段 | 说明 |
|---|---|
| CardId | 卡牌唯一编号 |
| Name | 原创卡牌名称 |
| Cost | 能量费用 |
| Cooldown | 使用后冷却回合数 |
| TargetRule | 目标规则 |
| Effect | 技能效果 |
| Tags | 类型标签 |

### 9.3 冷却规则

卡牌使用后不直接进入弃牌区，而是进入冷却区。冷却结束后进入弃牌区。

| 冷却值 | 规则 |
|---|---|
| 0 | 使用后立即进入弃牌区 |
| 1 | 下一个己方回合开始时进入弃牌区 |
| 2 | 经过 2 个己方回合开始后进入弃牌区 |

冷却区中的卡牌不能被抽到。

## 10. 部署规则

### 10.1 单位部署

玩家打出单位卡时，需要选择一条路线。

单位部署到所选路线的己方部署格。

部署失败条件：

- 能量不足。
- 部署格已有己方单位。
- 卡牌不允许部署到该路线。
- 当前处于不可出牌状态。

### 10.2 敌方部署

敌方单位部署到所选路线的敌方部署格。

敌方部署失败时，AI 选择下一张可用卡牌或跳过出牌。

### 10.3 召唤疲劳

单位部署当回合不行动。  
从下一次所属方单位行动阶段开始行动。

该规则用于保留反应时间，避免单位刚落地立即造成不可预期伤害。

## 11. 单位行动规则

### 11.1 基础行动

单位每次行动只能执行一种行为：

1. 若攻击范围内存在合法目标，执行攻击。
2. 若攻击范围内不存在合法目标，向前移动。
3. 若前方被阻挡且攻击范围内没有合法目标，停留。

### 11.2 攻击目标

单位只攻击同路线目标。

目标优先级：

1. 攻击范围内最近的敌方单位。
2. 若无敌方单位且敌方英雄在攻击范围内，攻击敌方英雄。

### 11.3 移动规则

单位每次行动按 Move 属性向前移动，默认 Move 为 1。

移动逐格检查。若目标方向上的下一格被单位占用，则停止移动。

若本次移动越过敌方英雄虚拟格，则停在最后一个战斗格。

### 11.4 英雄攻击范围

单位位于敌方英雄前一格且攻击范围覆盖英雄时，可攻击英雄。

近战单位攻击敌方英雄条件：

- 我方单位位于 Cell 6。
- 敌方单位位于 Cell 1。

远程单位攻击英雄条件：

- 攻击距离覆盖敌方英雄虚拟格。

## 12. 属性规则

### 12.1 基础属性

| 属性 | 说明 |
|---|---|
| Hp | 当前生命 |
| MaxHp | 最大生命 |
| Attack | 普通攻击伤害 |
| Range | 攻击距离 |
| Move | 每次行动移动格数 |
| Armor | 护甲，减少物理伤害 |
| Resist | 抗性，减少法术伤害 |
| Speed | 行动优先级，第一版保留字段，不参与计算 |

### 12.2 伤害公式

物理伤害：

`FinalDamage = Max(1, Attack - Armor)`

法术伤害：

`FinalDamage = Max(1, SpellDamage - Resist)`

真实伤害：

`FinalDamage = RawDamage`

治疗：

`FinalHeal = HealValue`

生命不能超过最大生命。

## 13. 状态规则

第一版只实现以下状态。

| 状态 | 效果 | 持续 |
|---|---|---|
| Stun | 无法行动 | N 次所属方行动阶段 |
| Shield | 获得护盾值，优先抵扣伤害 | 护盾耗尽或持续结束 |
| Taunt | 同路线敌人优先攻击该单位 | N 次敌方行动阶段 |
| Slow | 移动距离 -1，最低为 0 | N 次所属方行动阶段 |
| Poison | 回合开始受到固定伤害 | N 次所属方回合开始 |
| Silence | 被动技能失效 | N 次所属方行动阶段 |

状态持续时间在触发方对应阶段结算。

## 16. 敌方 AI

### 16.1 AI 目标

敌方 AI 不追求最优解，只提供稳定的 PVE 压力。

AI 行为目标：

- 保证每回合有合理出牌。
- 优先补弱路线。
- 优先解决即将攻击英雄的单位。
- 根据关卡类型形成差异。

### 16.2 AI 出牌流程

敌方回合出牌时按以下流程执行：

1. 计算三条路线威胁值。
2. 计算手牌中可用卡牌。
3. 优先使用可解决最高威胁路线的卡牌。
4. 若无防守需求，选择推进价值最高的路线部署单位。
5. 能量不足或无可用卡牌时结束出牌。

### 16.3 路线威胁值

对敌方而言，路线威胁值计算：

`Threat = 我方单位攻击总值 + 我方单位生命总值 * 0.3 + 我方最前单位位置权重`

我方单位越靠近敌方英雄，位置权重越高。

| 我方位置 | 权重 |
|---|---:|
| Cell 1 | 0 |
| Cell 2 | 1 |
| Cell 3 | 2 |
| Cell 4 | 4 |
| Cell 5 | 7 |
| Cell 6 | 10 |

### 16.4 AI 性格

第一版定义三种 AI 性格。

| 性格 | 行为 |
|---|---|
| Aggressive | 优先部署输出单位，倾向攻击低防路线 |
| Defensive | 优先防守最高威胁路线 |
| Balanced | 防守与推进权重均衡 |

### 20.2 操作规则

单位卡操作：

1. 点击手牌中的单位卡。
2. 可部署路线高亮。
3. 点击目标路线。
4. 单位进入部署格。
5. 扣除能量，卡牌进入冷却区。

技能卡操作：

1. 点击手牌中的技能卡。
2. 合法目标高亮。
3. 点击目标。
4. 立即结算效果。
5. 扣除能量，卡牌进入冷却区。

## 23. 原型验收标准

### 23.1 可玩标准

- 可以完成从进入战斗到胜负结算的完整流程。
- 至少有 10 个 PVE 关卡。
- 至少有 20 张可用卡牌。
- 敌方 AI 能完成基础部署和技能释放。
- 单局平均时长在 5 至 8 分钟。
- 玩家每回合平均至少有 1 张可打出的牌。

### 23.2 战斗标准

- 三条路线都能形成攻防压力。
- 单位上场后自动推进和自动攻击。
- 玩家不能手动控制单位普通移动。
- 技能卡能改变路线局势。
- 卡牌冷却能限制强卡循环。
- 关卡 1 至 5 可作为新手引导原型。
- 关卡 6 至 10 能体现敌方牌组差异。

### 23.3 技术标准

- 战斗逻辑与动画表现分离。
- 同一场战斗在相同随机种子下可复现。
- 卡牌、单位、关卡和敌方牌组使用配置数据驱动。
- 不在逻辑代码中硬编码具体卡牌效果数值。
- 能输出一份战斗日志用于调试。

## 24. 风险与限制

### 24.1 主要风险

- 自动推进导致玩家参与感不足。
- 冷却过长导致等待感过强。
- 三路路线差异不足导致选择无意义。
- 敌方 AI 太弱会变成单向推线。
- 敌方 AI 太强会暴露数值不足，造成挫败。

### 24.2 控制规则

- 每回合至少保证玩家有 1 个可执行动作。
- 低费卡数量不得低于牌组的 40%。
- 技能卡不超过牌组的 25%。
- 单局前 3 回合必须发生至少一次单位接触。
- 任一路线连续 3 回合无单位时，敌方 AI 提高该路线部署权重。
