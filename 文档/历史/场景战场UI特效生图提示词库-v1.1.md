## 1. 使用规则

- 场景提示词拼接：`P-CANVAS-ENVIRONMENT + 本文场景主体块 + 场景排除块`。
- 3D 建模参考拼接：`P-CANVAS-MODEL-SHEET + P-STYLE-UNIT + U编号主体块 + UNIT-MODEL-SHEET + 通用排除块 + 一致性提示词`。
- UI 生图只用于界面风格评审和布局参考。按钮、图标、边框、底纹与文字层必须在 Cocos Creator 或设计软件中重建。
- 特效生图只用于确定体积、方向、材质和颜色。正式特效由 3D Particle、Mesh Trail、Billboard 与 Decal 重建。
- 商店与广告素材执行低尺度版本，不直接裁切游戏内高尺度立绘。

## 3. 第一章十二个战场

```text
末烽堡外的清晨山道，左端为边军黑铁堡门和低矮拒马，右端为被失控役兵占据的断崖关口。密封的空白神册运输车停在左后方，只作为小型叙事地标。上路是碎石军道，下路是木栈补给道，两路之间由低矮烽墙分隔。冷灰天空中有一道被截断的赤金神位光轨，晨光从侧后方照亮可部署区域，气氛克制、戒备、尚未全面失控。
```



## 5. 3D 建模与动画参考

### 5.1 生产方式

每个 U001-U028 先用《角色与兵种生图提示词库-v1.1》的主体块生成一张 `UNIT-MODEL-SHEET`。每个 C001-C010 先用同文件的 `CHARACTER-MODEL-SHEET` 生成战场建模参考。通过评审后，将建模参考板作为模型、材质、骨架和动画的身份依据。生图不能代替正式 Mesh、Skeleton、Material、Animation Clip 和 Prefab。

### UNIT-MODEL-SHEET 单位 3D 建模适配

```text
生成该单位的实时3D战场建模参考板。保持成年比例或原始异兽骨架，明确正面、侧面、背面、四分之三视图中的头部、肩部、武器、翼根、甲片、机关连接和族属器官；服装、武器和背饰必须具有可建模厚度与连接关系。将细小纹样、刺绣、微小挂饰以及角色设定中存在的丝袜织纹归入贴图，不建立无效悬浮几何。最后一格展示固定45度正交战场投影，普通人形投影高度约96像素时仍可识别职业与朝向。中性浅灰背景，无场景、无特效、无文字和水印。
```

### BATTLE-IDLE 待机

```text
保持建模参考完全不变。生成骨骼动画待机关键姿势，重心稳定，武器或攻击部件处于可立即出手的位置；只表现轻微呼吸、织物下垂、族属器官或机械结构的小幅运动。主支撑点枢轴固定，不添加技能光效和场景。
```

### BATTLE-MOVE 移动

```text
保持建模参考完全不变。生成原地循环移动动画的中段关键姿势，主体顺推进方向受力，前后肢体、足部或机关支撑点关系明确，武器沿推进方向收束，披风、羽毛和附属结构向后受力；不包含根位移，主支撑点枢轴保持统一。
```

### BATTLE-ATTACK 攻击

```text
保持建模参考完全不变。生成攻击动画命中前关键姿势，力量从支撑点经主体传递到武器、角、爪或机关攻击部件，攻击方向和命中事件点清楚，轮廓外扩但不遮挡相邻单位。不要绘制命中特效、敌人和场景。
```

### BATTLE-HIT 受击

```text
保持建模参考完全不变。生成受到正面中等冲击的受击关键姿势，主体和武器或攻击部件合理后撤，主要支撑点仍然稳定，不改变模型比例，不出现伤口特写和血液飞溅。
```

### BATTLE-DEATH 退场

```text
保持建模参考完全不变。生成战败退场动画的中段关键姿势，人形单位失去重心并向后下方倒伏，异兽遵循原骨架，机关单位表现停摆、解锁或受控散件；武器和主要部件仍与主体关联。无肢解、无内脏、无大量血液，最终轮廓不得覆盖相邻格位。
```

### BATTLE-CAST 施法

```text
保持建模参考完全不变。生成施法或军令动画的蓄势关键姿势，手、法器或旗号构成明确动作路径，效果挂点清楚但不绘制大面积光效，不遮挡头部和武器。
```

### BATTLE-SUPPORT 治疗与屏障

```text
保持建模参考完全不变。生成治疗、净化或屏障动画的关键姿势，身体重心稳定，手势和器具指向目标，预留特效挂点，本图只保留动作本体。
```

### BATTLE-CAMERA-PREVIEW 正交战场预览

```text
将已通过的3D建模参考作为唯一身份依据，制作横向16:9正交战场渲染预览：同一模型分别真实旋转朝左和朝右，站在两条战线的标准格位中，固定45度俯角和统一主光。验证非对称纹章、护甲、发饰、武器握持、丝袜色块和翼根结构在两个朝向下均物理正确。单位投影高度约96像素，无UI、无技能特效、无镜像贴图、无文字。
```

## 12. 验收标准

- 十二个战场的剧情地标、两条战线和左右阵地完整，在 `1280×720` PC 浏览器视口和 Android 横屏预览中仍可区分关卡。
- 二十八个兵种和十名具名角色全部以通过的建模参考板生产模型与动画，脸型、体型、武器、纹章与主色不得漂移。
- 单位、特效、生命条和召唤格不互相遮挡；96像素单位仍能识别职责与朝向。
- UI 样机不承担最终文字与切图交付，所有文字、图标和组件在引擎中重建。
- 商店素材与游戏内素材分开审核，不以裁切隐藏高尺度内容。
- 生图不得直接充当战场单位、场景 Mesh 或完整技能序列帧。
- 全部素材通过原创相似性、年龄分级、人体结构、正交战场可读性、PC 浏览器运行和多比例裁切检查后进入生产。
