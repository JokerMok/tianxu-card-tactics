# Cocos A0 资源接入验收报告

版本：v0.2  
日期：2026-07-16  
状态：预览资源接入通过，正式动画与六层场景未通过

## 一、验收结论

Cocos Web Desktop A0 已接入 E104 合成场景板、C009 与 C001 主将卡面、U002 与 U008 动作姿势板及对应单位卡面。双方主将固定在双路中线外侧，不进入路线格与手牌；敌方主将受击时同步扣减生命、闪白和侧向位移。U002 与 U008 以两帧姿势预览显示在单个逻辑格内，手牌使用正式卡面缩略图。

本批资源只能用于布局、身份识别和替换接口验证。现有文件不含 Spine 骨骼数据、透明序列帧或 E104 六张独立视差层，不能据此判定 D017、D018 或二维美术 A0 完成。

## 四、对抗式复核

1. 首次挂载 Sprite 后，Cocos 将节点尺寸重置为源图尺寸，主将和卡面溢出画布。现已在挂载后重设 UITransform，并用 1920×1080 截图复核。
2. 首版灰底去除材质把单位整体裁成透明，自动资源计数仍显示正常。该材质已撤回，并增加 `runtimeUnitSprites=2` 断言，防止再次出现“资源已加载但画面为空”。
3. U002、U008 姿势板自带灰白底和大面积留白。运行时已紧裁切并限制在单格内，但这不是正式透明动画，状态保持 `preview-pose`。
4. E104 当前显示的是合成板主场景区域。没有六层独立图片，无法测试视差、无缝循环与前景遮挡。
5. C009、C001 当前是卡面预览。受击反馈由侧槽闪白和位移实现，未覆盖 Idle、HitLight、HitHeavy、Command、Critical、Defeat 六个独立动作。
6. 原始 PNG 共约 16 MiB，Web 构建增至约 19 MiB。正式交付应改用压缩纹理和按需加载，避免全量资源常驻。
