## 一、验收结论

Cocos Creator 3.8.8 Web Desktop A0 工程已建立并通过工程骨架验收。`2×12` 双路、六个部署格、固定主将侧槽、顶部投降、五张手牌、主将轻受击和二十四单位压力入口均可运行。

本结论不等于二维美术 A0 通过。当前角色、单位和 E104 均为程序化占位图形；C009、C001、U002、U008 的正式 Spine 或序列帧资产以及 E104 六层场景尚未接入，不得启动全兵种和全章节批量生产。

## 四、对抗式复核与修正

1. 首次构建沿用空模板的 `960×640` Canvas 中心，出现上下黑区；已改为运行时锁定 `1920×1080` 并使用全屏 Web 模板。
2. 首次压力场景的单位层位于路线层之后，指标为二十四但画面不可见；已调整渲染层级并增加截图复核。
3. 初版自动校验将最低帧率错误写为 45 fps，低于技术规范的 55 fps；已统一为 55 fps、P95 不高于 22 ms。
4. 二十四个独立占位节点曾降至 33.5 fps；工程占位改为每路一个批次节点。该优化不能代替真实 Spine 缓存模式测试。
5. 首批美术素材清单存在两个 `A0-09`；Cos 样衣已改为 `A0-10`。
6. 严格性能样本曾达到 60.0 fps，复核时降至 48.2 fps；已撤回单次通过结论，55 fps 与 P95 22 ms 门槛保持不变。
