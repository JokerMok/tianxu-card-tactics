## 2. 拼接方法

角色和单位提示词由四段组成：`画布与用途 + 风格母版 + 专属主体块 + 通用排除块`。技能、场景、UI 和特效使用各自独立母版。

生成步骤：

1. 先生成角色或单位的正面设定图，确定脸型、体型、服装和武器。
2. 将通过评审的设定图作为 `Image 1: identity and costume reference`。
3. 再生成卡面、头像、战场单位和商业裁切，并要求保持身份不变。
4. 卡名、费用、攻防、属性、技能描述和按钮文字由程序或排版软件叠加，不进入纯立绘提示词。

## 6. 一致性提示词

使用参考图继续生成时追加：

```text
Image 1是身份与服装唯一参考。严格保持脸型、五官间距、肤色、体型、发型、主轮廓、纹章、武器、材质关系和三种主色，不重新设计角色。只改变本次指定的姿态、镜头、表情或场景。若参考图与文字冲突，以参考图中的身份结构为准，以文字中的动作和画布要求为准。
```

## 7. 卡牌文字规则

- 纯立绘、卡框、卡背和纹理不生成任何文字。
- 最终卡名、费用、攻击、生命、护甲、五行、技能描述、稀有度和编号由 Unity 或网页 UI 叠加。
- 只在评审用整卡样机中允许生成文字，必须将每段文字放入引号并要求逐字显示；样机不能直接作为正式卡牌。
- 同一卡牌的重复张数复用同一张立绘，不重复生成不同画面。

## 8. 透明素材规则

需要透明背景时，先用纯品红 `#FF00FF` 背景生成，再执行本地抠图。羽毛、烟雾、薄纱、玻璃和水体属于复杂边缘，不以自动抠图结果直接交付；正式资产需人工蒙版或分层重绘。

## 10. 生成验收

- 角色年龄、性别、族属、武器和职责与配置一致。
- 卡面缩至 `120×180` 后仍能识别脸、武器、族属和主要动作。
- 人形角色手指、肩肘、骨盆、膝踝与武器握法正确。
- 裸露与半透明区域符合年龄分级；成人角色仍保持完整遮蔽。
- 卡框、卡背和套牌纹样不包含可识别文字、商标和现有IP图形。
- 战场单位缩至96像素后，二十八个兵种两两误认率不高于10%。
- 所有正式资产通过相似性、平台尺度和人工结构复核后才能进入项目。
