# 横屏战术卡牌手游完整系统设计文档

版本：v0.1  
日期：2026-06-30  
平台：手机横屏  
引擎：Unity 2D  
范围：历史 PVE 手游系统规划

> 本文档待按《PVE 全量复刻范围基线》重写；范围冲突时以新基线为准。

## 1. 文档定位

本文档用于定义横屏 2D 战术卡牌 PVE 手游的完整系统边界。

核心战斗规则以《核心战斗规则文档》为准。本文档在此基础上补全长期产品所需的卡牌成长、装备、天赋、章节地图、账号、商城、抽卡、任务、经济、运营和技术支撑系统。

本文档用于整体规划，不代表第一版全部开发。第一版必须先验证核心战斗闭环。

## 2. 产品规格

| 项目 | 内容 |
|---|---|
| 产品类型 | 横屏 2D PVE 战术卡牌手游 |
| 核心体验 | 玩家通过出牌、布线、技能干预影响三路自动推进战斗 |
| 核心对象 | 喜欢卡牌收集、PVE 推图、养成构筑和轻策略战斗的玩家 |
| 第一目标 | 验证三路自动推进卡牌战斗是否稳定有趣 |
| 长期目标 | 形成可扩展的 PVE 关卡、卡牌收集、角色成长和活动运营体系 |
| 商业化原则 | 付费提高收集和养成效率，不出售必须付费才能通过的硬门槛 |
| 内容原则 | 所有名称、美术、剧情、数值和卡牌效果均为原创 |
| 平台原则 | 手机横屏优先，UI 不按 PC 页游逻辑设计 |

## 3. 全局目标

### 3.1 核心目标

- 建立完整的 PVE 卡牌手游系统蓝图。
- 保留核心战斗的轻操作和自动推进特征。
- 支持长期卡牌收集、养成和章节推进。
- 支持账号、存档、商城、抽卡和运营活动。
- 让后续开发可按模块分期实施。

### 3.2 非目标

- 第一阶段不做 PVP。
- 第一阶段不做公会。
- 第一阶段不做交易和拍卖。
- 第一阶段不做玩家自制关卡。
- 第一阶段不做开放世界地图。
- 第一阶段不做复杂实时操作。
- 不复制任何已有游戏的名称、卡牌、美术、剧情和数值。

## 4. 核心闭环

### 4.1 单局战斗闭环

进入关卡 -> 抽牌 -> 部署单位 -> 单位自动推进 -> 技能干预 -> 击败敌方英雄 -> 获得奖励。

### 4.2 单次会话闭环

登录 -> 领取奖励 -> 推进章节 -> 消耗体力战斗 -> 获得资源 -> 升级卡牌或装备 -> 调整牌组 -> 继续挑战。

### 4.3 长期成长闭环

章节推进 -> 解锁新功能 -> 收集卡牌 -> 强化卡牌和英雄 -> 挑战更高难度 -> 获取稀有资源 -> 完善构筑。

### 4.4 商业化闭环

免费体验核心战斗 -> 通过任务和推图获得基础资源 -> 通过商城和抽卡提升收集效率 -> 继续挑战高难 PVE 内容。

## 6. 版本规划

### 6.1 Prototype

目标：验证战斗是否成立。

范围：

- 3 路 6 格战场。
- 20 张测试卡。
- 10 个 PVE 关卡。
- 基础敌方 AI。
- 战斗日志。
- 本地存档。

不包含：

- 账号。
- 商城。
- 抽卡。
- 装备。
- 天赋。
- 长线养成。

### 6.2 Vertical Slice

目标：验证完整手游循环。

范围：

- 章节 1。
- 30 至 40 张原创卡。
- 卡牌升级。
- 牌组编辑。
- 任务系统。
- 基础背包。
- 本地账号或游客账号。
- 章节奖励。

### 6.3 Alpha

目标：验证长期成长和经济。

范围：

- 3 个章节。
- 80 至 100 张卡。
- 卡牌突破。
- 装备系统。
- 天赋系统第一版。
- 体力系统。
- 货币系统。
- 商城无付费测试版。
- 抽卡无付费测试版。
- 云存档。

### 6.4 Soft Launch

目标：验证留存、付费和内容消耗速度。

范围：

- 5 个章节。
- 120 至 160 张卡。
- 完整商城。
- 完整抽卡。
- 日常、周常、成就。
- 活动系统。
- 支付接入。
- 埋点分析。
- 后台配置。

### 6.5 Release

目标：稳定上线。

范围：

- 7 个以上章节。
- 160 张以上卡。
- 完整新手引导。
- 完整运营后台。
- 客服和补偿工具。
- 版本热更新配置。
- 合规内容。

## 8. 战斗系统

### 8.1 范围

战斗系统沿用《核心战斗规则文档》：

- 手机横屏。
- 3 条路线。
- 每路线 6 个格子。
- 我方左侧，敌方右侧。
- 单位自动推进。
- 玩家通过出牌和技能干预战局。
- PVE 敌方由牌组和 AI 驱动。

### 8.2 战斗入口

战斗入口来自：

- 章节关卡。
- 教学关卡。
- 材料副本。
- 活动关卡。
- 测试工具。

### 8.3 战斗输出

战斗结束后输出：

- 胜负结果。
- 回合数。
- 英雄剩余生命。
- 上场卡牌。
- 消耗卡牌。
- 击杀单位。
- 伤害统计。
- 治疗统计。
- 关卡星级。
- 奖励结算。
- 战斗日志。

### 8.4 战斗校验

战斗必须支持：

- 相同随机种子可复现。
- 战斗逻辑与动画表现分离。
- 配置驱动卡牌效果。
- 战斗日志可回放关键事件。
- 关卡失败原因可分析。

## 9. 卡牌系统

### 9.1 卡牌类型

| 类型 | 作用 |
|---|---|
| 单位卡 | 部署单位，自动推进和攻击 |
| 技能卡 | 即时改变战局 |
| 英雄技能卡 | 由英雄或天赋生成，第一阶段预留 |
| 衍生卡 | 战斗中生成，不进入收藏 |

### 9.2 卡牌字段

| 字段 | 说明 |
|---|---|
| CardId | 唯一编号 |
| Name | 原创名称 |
| CardType | 单位、技能、英雄技能、衍生 |
| ClassTag | 职业标签 |
| FactionTag | 阵营标签 |
| RoleTag | 肉盾、输出、控制、治疗、召唤、辅助 |
| Rarity | 稀有度 |
| Cost | 能量费用 |
| Cooldown | 冷却回合 |
| BaseStats | 基础属性 |
| SkillIds | 技能列表 |
| UpgradeGroup | 成长曲线组 |
| UnlockSource | 来源 |
| IsCollectible | 是否可收藏 |

### 9.3 稀有度

| 稀有度 | 定位 | 成长上限 |
|---|---|---|
| Common | 基础构筑组件 | 低 |
| Rare | 明确功能卡 | 中 |
| Epic | 构筑核心卡 | 高 |
| Legendary | 战术核心或特殊机制 | 高 |

稀有度不等于必胜强度。高稀有卡提供构筑特性，不直接压制低稀有卡。

### 9.4 卡牌获得

来源：

- 章节首通。
- 章节掉落。
- 任务奖励。
- 成就奖励。
- 商城购买。
- 抽卡。
- 活动兑换。
- 碎片合成。

### 9.5 卡牌收藏状态

| 状态 | 说明 |
|---|---|
| Locked | 未获得 |
| Owned | 已拥有 |
| Upgradable | 可升级 |
| Maxed | 当前版本已满级 |
| Temporary | 临时卡，只在指定关卡或活动中使用 |

## 10. 牌组系统

### 10.1 牌组规则

| 项目 | 规则 |
|---|---|
| 牌组数量 | 玩家可保存 5 套牌组 |
| 每副牌数量 | 20 张 |
| 单卡携带上限 | Common/Rare 最多 2 张，Epic/Legendary 最多 1 张 |
| 技能卡上限 | 最多 6 张 |
| 衍生卡 | 不可加入牌组 |
| 空牌组 | 不可进入正式关卡 |

### 10.2 牌组校验

进入战斗前校验：

- 牌组数量是否满足。
- 卡牌是否已拥有。
- 单卡携带数量是否超限。
- 职业限制是否满足。
- 关卡特殊规则是否满足。

### 10.3 推荐牌组

新手阶段提供推荐牌组。

推荐牌组规则：

- 自动选择低费卡。
- 至少 40% 单位卡费用不高于 3。
- 至少包含 2 张防守卡。
- 至少包含 2 张远程或技能解场卡。

## 11. 卡牌升级系统

### 11.1 系统目标

卡牌升级用于提供长期成长目标。升级只改变卡牌基础属性和少量技能强度，不改变卡牌核心机制。

### 11.2 成长结构

| 成长层 | 内容 | 作用 |
|---|---|---|
| 等级 | 1 至 30 | 提升生命、攻击、护甲、抗性 |
| 突破 | 0 至 5 阶 | 提升等级上限 |
| 技能强化 | 0 至 3 阶 | 提升指定技能数值 |
| 精通 | 卡牌使用次数成长 | 提供少量非战斗奖励或外观奖励 |

### 11.3 等级上限

| 突破阶 | 等级上限 |
|---|---:|
| 0 | 10 |
| 1 | 15 |
| 2 | 20 |
| 3 | 25 |
| 4 | 30 |
| 5 | 30，解锁精通上限 |

### 11.4 升级材料

| 材料 | 来源 | 用途 |
|---|---|---|
| 金币 | 关卡、任务、商城 | 通用升级消耗 |
| 卡牌碎片 | 抽卡重复、关卡掉落 | 卡牌突破 |
| 职业徽记 | 精英关卡、活动 | 技能强化 |
| 通用尘 | 分解碎片或活动 | 替代少量碎片 |

### 11.5 碎片规则

获得重复卡牌时转化为对应碎片。

| 稀有度 | 重复转化碎片 |
|---|---:|
| Common | 5 |
| Rare | 10 |
| Epic | 25 |
| Legendary | 80 |

### 11.6 升级限制

- 卡牌等级不能超过玩家等级限制。
- 突破必须消耗同卡碎片或指定替代材料。
- 技能强化必须消耗职业徽记。
- 战斗原型阶段不启用升级系统。
- 数值提升不得让低章节关卡失去教学价值。

## 12. 英雄系统

### 12.1 英雄定位

英雄代表玩家在战斗中的职业方向。英雄决定可用天赋、部分卡牌限制和英雄被动。

### 12.2 第一批英雄原型

| 英雄原型 | 战斗倾向 | 牌组倾向 |
|---|---|---|
| 守卫者 | 防守、反击、护盾 | 肉盾和反击单位 |
| 奥术师 | 法术伤害、范围清场 | 技能卡和远程单位 |
| 追猎者 | 快攻、节奏、击退 | 低费单位和控制 |
| 祈愿者 | 治疗、续航、增益 | 辅助单位和持久战 |

名称为内部原型名，正式命名另行确定。

### 12.3 英雄属性

| 属性 | 作用 |
|---|---|
| HeroHp | 战斗生命 |
| HeroLevel | 英雄等级 |
| PassiveSkill | 被动技能 |
| TalentTreeId | 天赋树 |
| EquipSlots | 可装备槽位 |
| ClassCardRules | 职业卡使用规则 |

### 12.4 英雄获得

第一版默认 1 个初始英雄。  
后续英雄通过章节、活动或账号成长解锁，不通过纯付费硬锁。

## 13. 装备系统

### 13.1 系统目标

装备用于强化英雄和牌组风格，不直接绑定单张卡牌。避免每张卡都要单独穿装备导致管理成本过高。

### 13.2 装备槽位

| 槽位 | 主要属性 |
|---|---|
| 武器 | 攻击、法术伤害、英雄技能强化 |
| 护甲 | 英雄生命、护甲、减伤 |
| 饰物 | 抽牌、能量、冷却相关效果 |
| 旗帜 | 指定标签单位强化 |

### 13.3 装备稀有度

| 稀有度 | 副属性数量 | 特殊效果 |
|---|---:|---|
| Common | 0 | 无 |
| Rare | 1 | 无 |
| Epic | 2 | 可能有 |
| Legendary | 3 | 必有 |

### 13.4 装备属性

装备属性只能影响以下范围：

- 英雄生命。
- 英雄护甲。
- 指定标签单位生命。
- 指定标签单位攻击。
- 技能卡伤害。
- 治疗效果。
- 开局手牌数量。
- 首回合能量。
- 指定卡牌冷却减少。

禁止属性：

- 直接跳过战斗。
- 直接让抽卡概率变化。
- 直接提高付费奖励。
- 无限抽牌。
- 无限能量。

### 13.5 装备获得

来源：

- 精英关卡。
- Boss 关卡。
- 材料副本。
- 活动。
- 装备宝箱。
- 商城限购。

### 13.6 装备成长

装备可升级，不做随机洗练第一版。

| 成长 | 规则 |
|---|---|
| 等级 | 消耗金币和强化矿 |
| 升阶 | 消耗同槽位材料 |
| 分解 | 返还部分强化矿 |
| 套装 | Alpha 后启用 |

## 14. 天赋系统

### 14.1 系统目标

天赋用于让同一英雄产生不同构筑方向。天赋提供策略差异，不制造不可逆错误。

### 14.2 解锁条件

天赋系统在账号等级达到 8 级后开启。  
天赋点通过账号等级和章节星数获得。

### 14.3 天赋结构

每个英雄拥有 3 条天赋线。

| 线 | 方向 |
|---|---|
| 生存线 | 英雄生命、防御、护盾 |
| 输出线 | 单位攻击、技能伤害 |
| 节奏线 | 抽牌、能量、冷却、部署 |

### 14.4 天赋规则

- 每级账号获得 1 点天赋点。
- 每章星数宝箱可获得额外天赋点。
- 天赋可免费重置。
- 战斗前可切换天赋方案。
- 每个英雄最多保存 3 套天赋方案。

### 14.5 天赋限制

- 不允许天赋改变抽卡概率。
- 不允许天赋解锁付费专属关卡。
- 不允许天赋使基础战斗规则失效。
- 不允许天赋导致某一路线永远无法被攻击。

## 15. 章节地图系统

### 15.1 系统目标

章节地图承载主线 PVE 内容、系统解锁、关卡难度递进和资源投放。

### 15.2 地图结构

## 22. 抽卡系统

### 22.1 抽卡目标

抽卡用于卡牌收集和卡牌碎片获取。抽卡不作为唯一获得卡牌的方式。

### 22.2 卡池类型

| 卡池 | 内容 | 开放条件 |
|---|---|---|
| 标准卡池 | 全职业基础卡和稀有卡 | 账号 12 级 |
| 职业卡池 | 指定英雄职业倾向卡 | 解锁对应英雄 |
| 限时卡池 | 限时新卡或主题卡 | 活动开放 |
| 新手卡池 | 前 20 抽保底构筑核心 | 新账号 |

### 22.3 抽卡货币

- 抽卡券。
- 钻石。
- 活动抽卡券。

### 22.4 基础概率

| 稀有度 | 概率 |
|---|---:|
| Common | 60% |
| Rare | 28% |
| Epic | 10% |
| Legendary | 2% |

实际概率以卡池配置为准，必须在游戏内公开。

### 22.5 保底规则

- 每 10 抽至少获得 1 张 Epic 或以上。
- 每 80 抽至少获得 1 张 Legendary。
- 获得 Legendary 后大保底计数重置。
- 限时卡池计数在同类型限时卡池中继承。
- 新手卡池前 20 抽至少获得 1 张指定构筑核心卡。

### 22.6 重复卡转化

已拥有卡牌再次获得时转化为碎片。卡牌未满突破时保留为对应碎片；满突破后额外转化为通用尘。

### 22.7 抽卡限制

- 抽卡不能产出装备。
- 装备宝箱与卡牌抽卡分离。
- 抽卡不能产出账号经验。
- 抽卡不能直接跳过章节。
- 概率、保底和卡池内容必须可查。

## 39. 数值原则

### 39.1 战斗数值

- 低费卡保证前 3 回合可行动。
- 高费卡必须有明显节奏代价。
- 每局平均 5 至 8 分钟。
- 关卡失败应能通过换牌组、升级或调整路线解决。

### 39.2 成长数值

- 卡牌升级提升稳定，但不能替代构筑。
- 装备提供风格强化，不覆盖卡牌选择。
- 天赋提供方向，不提供无脑通解。
- 章节难度按核心机制逐步增加。

### 39.3 经济数值

- 免费玩家可持续推进主线。
- 付费玩家提高收集效率和养成速度。
- 抽卡重复必须有成长价值。
- 商城商品不得破坏章节奖励价值。

## 41. 对抗式审查

### 41.1 风险一：系统过早膨胀

问题：完整系统规划容易诱导团队跳过核心战斗验证，直接做账号、商城和抽卡。  
处理：Prototype 只做战斗、卡牌、关卡和日志。核心战斗未达标前，不进入商业化开发。

### 41.2 风险二：自动推进参与感不足

问题：单位自动行动会降低操作感。  
处理：强化路线选择、出牌时机、技能卡和牌组构筑。每回合必须至少有 1 个有效选择。

### 41.3 风险三：成长系统压过策略

问题：卡牌升级、装备和天赋可能让数值碾压替代策略。  
处理：关卡设计必须允许通过构筑和操作解决问题，成长只能降低难度，不能成为唯一解。

### 41.4 风险四：抽卡破坏 PVE 公平

问题：强卡只来自抽卡会导致主线卡关和付费压力。  
处理：主线核心卡必须可通过章节、任务或碎片合成获得。抽卡提供更快收集，不做唯一入口。

### 41.5 风险五：内容消耗速度过快

问题：PVE 手游容易被快速打穿。  
处理：用星级目标、精英关、挑战关、活动关和构筑任务延长内容寿命，不用单纯提高血量拖时间。

### 41.6 风险六：服务端成本过早增加

问题：账号、商城、抽卡和云存档会显著增加开发成本。  
处理：Prototype 和 Vertical Slice 使用本地存档与模拟商城。Soft Launch 前再接真实服务端和支付。
