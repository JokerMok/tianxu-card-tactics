## 1. 设计目标

项目采用“成人东方神权时装奇幻”风格。角色立绘以成熟、危险、华贵和具有身体张力的形象承担第一吸引力；封神与山海背景通过神位结构、异兽器官、五行材质和仪式装置表达，不复原具体朝代服饰。

美术必须同时满足四项要求：卡牌立绘具有收藏吸引力，角色服装具备 Cos 制作空间，战场单位在手机横屏中清晰可辨，商业发行素材符合目标平台规范。

### 1.1 设计方向 SPEC

| 项目 | 结论 |
|---|---|
| 视觉问题 | 旧方案过于传统，角色吸引力、时装感和传播记忆点不足 |
| 目标用户 | 偏好精美角色立绘、成人向审美、卡组构筑和东方幻想题材的成年用户 |
| 使用场景 | 横屏手机战斗、竖版卡牌浏览、角色详情、宣传图和线下 Cos |
| 风格核心 | 神权高定 50% + 山海生体 30% + 废序艳甲 20% |
| 非目标 | 历史复原、传统仙侠、古装影楼、Q 版、低龄二次元、赛博街头、欧美重甲写实 |
| 完成标准 | 角色缩略图、战场轮廓、成年感、性感度、世界观识别和 Cos 可实现性全部通过验收 |

## 2. 风格语法

### 2.1 神权高定

神位不是古代官服，而是一套穿戴在身体上的权力系统。服装以不对称裁剪、贴体结构、长垂片、悬挂式神印和仪式金属件构成。神职越高，结构越完整；失位者的服装会出现断开的闭环、错位封条和被剥离的权力部件。

### 2.2 山海生体

羽、鳞、石肤、灵体和机关义体必须与骨架、动作及生态相连。异质结构集中在肩背、髋侧、四肢末端和武器连接处，不使用随机长角、满身眼睛或无功能触手。

### 2.3 废序艳甲

战斗装备采用局部重甲与大面积贴体软甲的对比。甲片保护实际受击区，裸露和半透明区域用于表现身份、力量来源与身体自信。破损只能发生在外层披挂和非承力装饰上，不能以失去基本遮蔽制造噱头。

## 3. 成人向边界

### 3.1 基本要求

- 所有具备性感表达的角色设定年龄不得低于二十一岁，五官、体态、妆容和语言必须具有明确成年感。
- 允许加入二十一岁以下的年轻角色，具体服装、姿态、镜头、互动与宣传限制执行《角色年龄分级与表现规范-v1.0》；年轻角色不承担成人性感卖点。
- 二十一岁以上成人角色允许深领、露背、露腰、高开衩、贴体裁剪、局部半透明外层、吊带与腿部装饰；乳头、下体和臀沟必须由不透明结构完整遮蔽。
- 常规版与特殊版中所有明确为二十一岁以上的女性角色均配置长筒丝袜。丝袜颜色、纹样、织物密度和功能结构随角色、族属与职业变化，不统一使用黑色；袜口止于骨盆护片、短甲或高腰底甲下缘，不覆盖骨盆中心。十八至二十岁及未成年角色不继承本规则。
- 允许回眸、侧身扭转、交叠腿、半跪、倚靠武器、手指贴唇、拉紧手套或束带等性暗示动作。
- 禁止性行为、模拟性行为、触摸私密部位、体液暗示、束缚虐待取乐、偷拍视角及只对准胸部或下体的构图。

### 3.2 性感设计方法

性感来自权力感、身体控制和服装张力，不依赖全员同一身材或无理由暴露。每名角色只确定一至两个主要展示区域，并由职业动作或族属结构提供理由。

| 维度 | 执行规则 |
|---|---|
| 成熟感 | 成年骨相、明确下颌与鼻梁结构、克制表情；女性不使用幼态大眼和短下巴 |
| 体态 | 女性至少覆盖高挑、健美、丰润、强壮四类体型；男性覆盖成熟硬朗与冷峻修长 |
| 展示区域 | 每人限定一至两个主区域，如肩背、腰腹、腿部、胸颈或手臂，不全身同时抢焦点 |
| 动作 | 姿态首先说明角色正在掌控、引诱、审判、狩猎或交涉，其次才表达性感 |
| 镜头 | 50-85mm 等效视角为主；低机位可表现压迫感，不使用胯下、裙底和偷窥机位 |
| 表情 | 直视、轻蔑、审视、克制笑意或战斗兴奋；禁止无意识呆滞和统一媚笑 |

## 4. 人体与服装

| 项目 | 规范 |
|---|---|
| 人体比例 | 成年角色 7.5-8.5 头身；不得通过过度拉长四肢破坏关节位置 |
| 女性阵容 | 首发核心具名角色按八女二男配置；八名女性不得共用同一脸型、胸腰比和站姿 |
| 身体结构 | 肩、胸廓、骨盆、膝踝位置准确；贴体服装必须反映受力与褶皱，不做塑料皮肤 |
| 内层 | 贴体连身衣、胸衣式承托、短甲裤、缠带或鳞膜，负责完整遮蔽与动作安全 |
| 中层 | 甲片、束带、腰封、武器挂点和族属器官连接，负责职业与战斗逻辑 |
| 外层 | 长袖、披挂、羽尾、薄纱、飘带或断裂神印，负责动势与远距离轮廓 |
| 材质上限 | 单角色主材质不超过五种；皮肤、织物、金属、半透明层和族属材质必须可区分 |
| 装饰密度 | 面部、胸颈和持械手附近保留视觉静区；细碎挂件不得覆盖整个轮廓 |

### 4.1 材质库

优先使用黑曜釉、珍珠丝、漆皮、烟透纱、冷银、赤金、玉质薄片、鳞膜、羽绒边和矿晶。木材、麻布、厚皮革与仿古青铜只作局部功能材料，不再主导整体风格。

## 6. 色彩与光照

### 6.1 总色盘

| 色彩 | 色值 | 用途 |
|---|---|---|
| 墨黑 | `#111214` | 主背景、内层服装 |
| 骨白 | `#E7E0D2` | 文本、神庭织物、视觉留白 |
| 朱砂 | `#B93436` | 敌意、火、危险提示 |
| 玉青 | `#2FAE9B` | 玩家阵营、契约和可交互状态 |
| 赤金 | `#C69A45` | 神权、稀有度和仪式金属 |
| 深靛 | `#353B73` | 水、冥裔和夜景过渡 |
| 酸绿 | `#9AAE43` | 异兽生体与木系局部点色 |

单个角色的主色不超过三种，五行色只用于力量来源和技能反馈，不能把人物整体染成属性色。皮肤色保持真实跨度，不用统一冷白滤镜。

### 6.2 光照

- 立绘采用一处明确主光、一处弱轮廓光和环境反射；皮肤高光柔和，金属与漆皮高光边缘清晰。
- 角色面部、持械手和主要展示区域必须处于同一阅读路径，强光不得同时争夺三处以上焦点。
- 战场单位统一左上主光。敌方翻转朝向时，纹章、文字、持械手与光照需要单独修正。
- 禁止全屏紫蓝霓虹、廉价柔焦、过度油亮皮肤和无来源边缘光。

### 6.3 五行编码

沿用《战斗属性与克制规则-v1.0》的金、木、水、火、土、无相体系。图标必须通过断刃、枝脉、潮环、焰隙、层岩和空环六种轮廓区分，颜色只作辅助。角色服装不因五行改变基础结构。

## 7. 卡牌立绘

- 母版为 `2048×3072`、纵向 `2:3`，不含卡框、名称和数值。
- 具名角色以膝上、全身或坐姿权力构图为主；普通单位优先表现武器、职业动作和编制关系。
- 头部距顶边不少于画面高度的 8%，左右各留 6%，底部 18% 为信息栏裁切区。
- 面部在 `120×180` 缩略图中仍须可读；武器、族属结构和主展示区域不能被卡框同时遮挡。
- 同一角色最多保留一个主要性暗示动作。服装受力、手指、关节、武器握法和遮蔽结构必须正确。
- 背景只提供身份和场景线索，不使用宫殿、月亮、花瓣、烟雾等通用元素填满画面。

## 8. 战场单位

战场单位采用“3D 或高精度分层绘制后渲染为 2D 序列帧”的路线，统一四分之三侧视角。不能直接缩小卡牌立绘，也不能用卡面图标代替单位。

| 项目 | 规范 |
|---|---|
| 单帧母版 | `1024×1024` 透明背景，运行时降采样至 256 或 512 |
| 基础状态 | Idle、Move、Attack、Hit、Death |
| 扩展状态 | Cast、Heal、Stun、Burn、Freeze、Barrier |
| 帧率 | Idle 8-12 fps；Move 12-16 fps；Attack 12-18 fps |
| 轮廓 | 96 像素高度下仍能通过武器、翼根、甲片、发型或外层长摆识别 |
| 服装调整 | 立绘中的薄纱和高开衩可在战场版增加贴体内层；不得改变角色主轮廓和标志色 |
| 特效 | 与角色分层输出，不遮挡攻击方向、生命条和召唤格 |

## 9. 环境与 UI

### 9.1 战场环境

环境使用“破碎神权建筑 + 山海生态侵入 + 战时功能设施”的组合。设计分辨率为 `3840×1080`，分为天空、远景地标、中景建筑、战线路面、前景遮挡和环境粒子六层。两条路线靠地面材质和地标区分，网格只在部署时显现。

### 9.2 UI

UI 采用暗色陈列台与仪式装置语言：墨黑平面、骨白文字、朱砂警告、玉青交互、赤金稀有度。边框使用细金属线、断环和切角，不使用厚重木框、皮革底、卷轴、仿古铜器或大面积蓝紫渐变。

卡框圆角不超过 4 像素。单位、技能、五行、攻防型和稀有度均有固定标记位；可用、选中、禁用、托管和非法目标必须同时具备颜色与形状差异。

## 10. Cos 制作规范

每名核心角色必须交付正、侧、背三视图，服装拆层图，材质板，五金件尺寸，妆发图和武器拆分图。

| 项目 | 验收要求 |
|---|---|
| 识别点 | 每人最多四个主要识别点，二米距离可辨认 |
| 穿着安全 | 内层提供完整遮蔽；抬手、坐下、迈步和半跪时不走光 |
| 穿戴时间 | 单人协助下三十分钟内完成 |
| 持续穿着 | 连续四小时可站立、行走和坐下，无硬件持续压迫颈部或腰部 |
| 结构重量 | 单件头饰不超过 0.8 千克；单侧肩件不超过 1.2 千克 |
| 武器运输 | 可拆为最长不超过 80 厘米的部件，连接处不位于主要镜头面 |
| 可维护性 | 易损羽片、薄纱、挂饰和发光件可单独替换 |

## 11. 商业发行边界

成人向审美不等于色情内容。发行前按地区和平台重新确认评级、商店素材及广告规范。

- 游戏内立绘遵守本规范的完整遮蔽和禁止行为要求。
- 商店图、开屏广告和投放素材采用低尺度构图：减少胸部和臀部聚焦，避免半跪、床榻、手指贴唇等强性暗示动作。
- 商店素材可以更换姿态和裁切，但角色服装结构、年龄、身份与游戏内容必须真实一致，不得隐瞒实际内容规避审核。
- 禁止使用现有商业游戏、漫画、影视或艺人的可识别脸型、服装、纹章和构图。封神与山海只使用公共文化母题，新增角色和视觉资产保持原创。

提审前重新核对 [Apple App Review Guidelines 1.1.4](https://developer.apple.com/app-store/review/guidelines/#objectionable-content) 与 [Google Play Sexual Content and Profanity](https://support.google.com/googleplay/android-developer/answer/9878810?hl=zh-Hans)。平台政策更新后，以提审时规则为准。

## 13. 验收标准

- 十名首发角色均明确为二十一岁以上，成年感评审不得出现年龄歧义。
- 新增二十一岁以下角色必须标注年龄分级；未满十八岁的角色不得出现任何性感表达，十八至二十岁角色执行青年低尺度规则。
- 十名角色黑色剪影盲测中，目标用户对角色的两两误认率不高于 10%。
- 八名女性在脸型、体型、展示区域、服装结构和姿态上至少有三项明显差异。
- 卡牌缩至 `120×180` 后可识别面部、武器、族属和主色；战场单位缩至 72-96 像素后可识别职业轮廓。
- 成人角色目标用户测试中，“精美度”“成年性感度”“新鲜感”均值不低于 4.0，“传统古装感”均值不高于 2.0；年轻角色单独执行年龄适配与非性化验收。
- Cos 结构由至少一名服装制版人员和一名道具制作人员复核，无不可制作悬浮件、无动作走光风险。
- 商店素材与游戏内素材分别完成平台边界检查，禁止以降低角色年龄感、隐藏实际内容或复制现有 IP 通过验收。
