# PRD-横屏战术卡牌手游

版本：v0.1  
日期：2026-06-30  
状态：历史原型稿，待按《PVE 全量复刻范围基线》重写

> 本文档中的三路战斗和原型范围已失效，不得作为开发或验收依据。

## 1. Summary

本项目是一款手机横屏 2D PVE 战术卡牌手游。玩家通过抽牌、部署单位、选择路线和释放技能影响三路自动推进战斗。

第一阶段只验证核心战斗。完整产品将包含卡牌收集、卡牌升级、装备、天赋、章节地图、账号、商城、抽卡、任务、活动和运营系统。

## 3. Background

现有目标是做一款受经典页游战术卡牌体验启发、但名称、卡牌、美术、剧情、数值全部原创的手机横屏游戏。

核心体验不做实时微操。玩家主要负责出牌时机、路线选择、资源分配和技能干预。单位上场后自动推进和攻击。

当前已有《核心战斗规则文档》。本 PRD 用于把产品从战斗原型扩展为完整手游系统规划。

## 4. Objective

### 4.1 目标

建立可分期开发的 PVE 战术卡牌手游系统。

### 4.2 成功标准

| 阶段 | 标准 |
|---|---|
| Prototype | 完成 20 张卡、10 个关卡、完整战斗闭环 |
| Vertical Slice | 完成第一章、牌组编辑、卡牌升级、任务和奖励 |
| Alpha | 完成账号、云存档、装备、天赋、商城、抽卡模拟闭环 |
| Soft Launch | 完成支付、订单、活动、邮件、后台、埋点和合规 |

### 4.3 核心指标

- 首局完成率。
- 章节 1 完成率。
- 单局平均时长。
- 每回合有效选择数。
- D1 留存。
- D7 留存。
- 卡牌升级参与率。
- 抽卡参与率。
- 付费转化率。

## 5. Market Segment(s)

| 用户 | 需求 |
|---|---|
| 卡牌收集玩家 | 想持续获得新卡和构筑目标 |
| PVE 推图玩家 | 想通过关卡、Boss 和章节推进获得成长 |
| 轻策略玩家 | 想有策略选择，但不想做高频操作 |
| 养成玩家 | 想升级卡牌、装备和天赋形成长期目标 |

第一阶段优先服务轻策略 PVE 玩家，不优先服务竞技 PVP 玩家。

## 6. Value Proposition(s)

| 价值 | 说明 |
|---|---|
| 低操作压力 | 单位自动推进，玩家专注出牌和布线 |
| 有策略空间 | 三路攻防、卡牌冷却、技能干预形成决策 |
| 可长期成长 | 卡牌升级、装备、天赋和章节奖励提供目标 |
| 适合手机横屏 | UI、节奏和操作按手机设计 |
| 原创资产 | 不复用旧游戏名称、美术、卡牌、剧情和数值 |

## 7. Solution

### 7.1 UX

主战斗界面：

- 左侧为我方英雄。
- 右侧为敌方英雄。
- 中间为三条横向战斗路线。
- 底部为手牌。
- 右下为结束回合。
- 左下为能量。

主界面入口：

- 章节。
- 牌组。
- 卡牌。
- 英雄。
- 任务。
- 背包。
- 商城。
- 抽卡。
- 活动。
- 设置。

### 7.2 Key Features

| 功能 | 说明 |
|---|---|
| 核心战斗 | 三路自动推进 PVE 战斗 |
| 卡牌系统 | 单位卡、技能卡、稀有度、标签、收藏 |
| 牌组系统 | 20 张牌组、合法性校验、推荐牌组 |
| 卡牌升级 | 等级、突破、技能强化、碎片 |
| 英雄系统 | 职业方向、英雄被动、装备和天赋承载 |
| 装备系统 | 英雄装备、升级、分解、套装预留 |
| 天赋系统 | 三条天赋线、重置、方案切换 |
| 章节地图 | 普通、精英、Boss、星级、章节宝箱 |
| 账号系统 | 游客、绑定、云存档、找回和删除 |
| 商城系统 | 每日、资源、卡牌、装备、礼包、活动商店 |
| 抽卡系统 | 标准、职业、限时、新手卡池，公开概率和保底 |
| 任务系统 | 新手、日常、周常、成就、活动任务 |
| 运营系统 | 活动、邮件、公告、补偿、后台配置 |

### 7.3 Technology

客户端：

- Unity 2D。
- 配置驱动。
- 战斗逻辑和表现分离。
- 本地模拟器和战斗日志。

服务端：

- 账号。
- 云存档。
- 支付校验。
- 抽卡保底。
- 商城限购。
- 邮件和活动。
- 运营后台。

### 7.4 Assumptions

- 核心乐趣来自三路自动推进和出牌决策。
- PVE 足以支撑第一阶段验证。
- 玩家接受横屏手游形态。
- 长线成长可以通过卡牌、装备和天赋支撑。
- 商城和抽卡必须延后到战斗闭环验证后。
