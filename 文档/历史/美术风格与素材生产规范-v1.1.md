# 美术风格与素材生产规范

版本：v1.1  
日期：2026-07-13  
状态：首批生产基线

## 1. 视觉定位

项目采用写实奇幻战棋风格。卡牌以高完成度角色立绘承载收藏价值，战场单位以独立建模或分层渲染资产保证动作、轮廓和阵营识别。整体气质强调冷峻秩序、真实材质、有限魔法光效和清晰战术信息，不采用 Q 版、低龄卡通、夸张大头、短肢比例或玩具塑料质感。

## 2. 造型基线

| 项目 | 规范 |
|---|---|
| 人体比例 | 成年角色按 7.5-8 头身设计；重甲单位可通过甲胄扩大体块，不改变头身比例 |
| 轮廓 | 同一兵种在 96 像素高度下仍能通过武器、肩线、披风和体块识别 |
| 装备 | 结构符合受力与活动逻辑；金属、皮革、织物、木材和岩石必须具有明确材质差异 |
| 面部 | 写实五官，避免幼态圆脸、过大眼睛和夸张表情 |
| 魔法 | 作为局部功能光源使用，不覆盖武器、手势和受击位置 |
| 装饰 | 阵营纹章集中在盾牌、肩甲、旗帜和卡框，不满铺全身 |

## 3. 色彩与光照

| 阵营/功能 | 主色 | 辅色 | 禁止 |
|---|---|---|---|
| 玩家阵营 | 氧化青绿、冷银 | 象牙白、旧金 | 大面积荧光青 |
| 敌方阵营 | 暗朱红、黑铁 | 灰白、焦褐 | 纯红满屏和高饱和血色 |
| 羽民 | 松针绿、风化青 | 浅木、冷灰 | 纯白天使羽翼与单一翠绿色 |
| 鳞民 | 深青、贝灰 | 铜绿、暗绛 | 统一蓝色皮肤与廉价海盗造型 |
| 山灵 | 石灰、铁锈红 | 黄铜、苔绿 | 通体棕色与圆滚石怪轮廓 |
| 冥裔 | 褪靛、烟灰 | 旧银、幽白 | 统一骷髅形态与荧光紫 |
| 巧民 | 陶红、木褐 | 青铜、麻白 | 蒸汽朋克锅炉与现代枪械 |
| 异兽 | 炭黑、暗赭 | 骨白、余烬红 | 卡通橙与玩具毛绒质感 |
| 技能 | 冰蓝、琥珀金、灼红按属性区分 | 中性烟灰 | 紫蓝色作为统一万能魔法色 |

卡牌立绘采用有方向的电影式主光和弱环境补光；战场单位采用统一左上方主光，敌方单位仅翻转朝向，不翻转光照和纹章文字。

### 3.1 五行视觉编码

| 五行 | 主色 | 形状与材质 | 禁止 |
|---|---|---|---|
| 金 | 冷银、象牙白 | 断口、锐角、金属刻痕 | 大面积金黄色和货币符号 |
| 木 | 松绿、药草青 | 枝节、叶脉、纤维生长 | 通用绿色光团 |
| 水 | 深青、灰蓝 | 波纹、水滴、流动边缘 | 霓虹蓝和纯冰晶替代全部水术 |
| 火 | 暗朱、余烬红 | 火舌、炭化边、热变色 | 满屏纯红和无光源火焰 |
| 土 | 石灰、旧赭 | 方岩、层理、夯土裂纹 | 黄褐色圆球和沙尘遮屏 |
| 无相 | 中性灰、旧银 | 空心圆、军令刻线 | 使用紫色冒充万能属性 |

五行图标保持单色轮廓下可辨认，不能依赖颜色。攻型图标分别使用刃痕、枪尖、锤面和术印；防型图标分别使用轻甲片、重盾、巨躯轮廓和灵体空心纹。图标不得直接照搬现代游戏的专有图形。

## 4. 卡牌立绘

- 母版尺寸：`2048×3072`，纵向 `2:3`，不含卡框、名称、数值和文字。
- 构图：单位牌以膝上或全身动势为主，面部和标志性武器必须进入安全区；技能牌表现单一明确事件，不以抽象光团代替效果。
- 安全区：主体头部距离顶边不少于画面高度的 8%；左右各保留 6%；底部 18% 可被信息栏裁切。
- 镜头：35-70mm 等效视角；避免广角变形、鱼眼和俯拍大头。
- 输出：无损 PNG 或 95 质量以上 JPG；保留分层源文件、色彩空间和版本号。
- 同一单位的卡牌立绘与战场单位共享服装、武器、纹章和色板，但允许卡牌增加环境叙事与局部特效。

## 5. 战场单位

战场单位不得直接缩小卡牌立绘。首版采用“3D 或高精度分层绘制后渲染为 2D 序列帧”的生产路线，统一四分之三侧视角，玩家朝右、敌方朝左。

| 项目 | 规范 |
|---|---|
| 单帧画布 | `1024×1024` 透明背景母版，按运行目标降采样至 256 或 512 |
| 站位基准 | 双脚接地中心统一，武器伸展不得改变碰撞格中心 |
| 基础状态 | Idle、Move、Attack、Hit、Death |
| 扩展状态 | Cast、Heal、Stun、Burn、Freeze、Barrier |
| 帧率 | Idle 8-12 fps；Move 12-16 fps；Attack 12-18 fps |
| 方向 | 单方向资产可水平镜像，但纹章、文字、持械手和光照异常必须单独修正 |
| 阴影 | 独立软阴影层，不烘焙进角色透明图 |
| 特效 | 与角色分层输出，便于取消、调速、换色和性能降级 |

## 6. 战场环境

- 设计分辨率：`3840×1080`，适配 16:9、19.5:9 和 21:9 横屏裁切。
- 分层：远景天空、远景地标、中景建筑、战线路面、前景遮挡、环境粒子六层。
- 两条路线必须通过地面材质、边界物和高度差自然识别；网格线只作为交互辅助，不承担主要分路职责。
- 己方和敌方 `2×3` 召唤区在环境中具有不同地面纹章，选择卡牌时再叠加高亮。
- 背景对比度低于单位，英雄端点和中央交战区不得出现高频纹理。

## 7. UI 与卡框

- UI 采用锻造金属、染色皮革、旧木和磨砂玻璃的受控组合，不使用厚重拟物边框覆盖内容。
- 卡框圆角不超过 4 像素；单位、技能、稀有度和阵营通过窄边、角标与纹章组合编码。
- 数值区保持高对比纯色底，不在复杂立绘上直接压小字。
- 单位卡框预留攻型、防型和五行三个稳定标记位；技能卡框预留五行和目标范围标记位，标记变化不得挤压卡名。
- 可用、选中、禁用、托管和非法目标必须同时具备颜色与形状差异。
- 图标仅用于功能按钮和素材缺失占位，不得作为成品卡牌主视觉或战场单位。

## 8. 文件与版本

命名格式：`类别_阵营_编号_用途_状态_版本`。示例：`unit_human_U001_battle_idle_v001.png`、`card_human_U001_illustration_v003.psd`。

目录固定为：

```text
Art/
  Source/CardIllustration/
  Source/UnitRender/
  Source/Environment/
  Source/UI/
  Export/Cards/
  Export/Units/
  Export/Environment/
  Export/UI/
```

## 9. 验收标准

- 卡牌立绘缩放至 120×180 后仍能识别面部、武器和阵营。
- 战场单位缩放至 72-96 像素高度后，十个首发兵种的两两误认率不高于 10%。
- 全部单位在 Idle、Move、Attack、Hit、Death 五种状态下脚底不漂移、轮廓不跳变。
- 844×390 真机视口下单位、生命条、状态和召唤格不互相遮挡。
- 同一单位的卡牌立绘、战场渲染、头像和技能特效通过服装结构与色板核对，无跨版本造型漂移。
- 五行与攻防图标在去色、红绿色弱和 72 像素战场单位尺寸下仍可辨认。
