# Cocos A0 视觉重构验收报告

版本：v0.3  
日期：2026-07-16  
状态：高保真布局通过，正式运行时美术与性能未通过

## 一、结论

原 A0 页面与目标效果差距过大，只能证明 Cocos 工程、格位和资源加载可运行，不具备视觉验收价值。本轮已按高保真参考重构战场占比、双路路面、左右主将、顶部 HUD、手牌位置和卡面层级，并移除画面中的压力测试入口与受击调试按钮。

当前版本可作为后续正式素材接入底座，但仍不是目标效果的完整实现。主将使用带背景卡面，U002、U008 使用无透明通道的姿势板，UI 外框为程序绘制，E104 仍是合成板裁切。这四项未替换前，不得判定视觉 A0 完成。

## 二、本轮修正

| 项目 | 修正结果 |
|---|---|
| 战场 | 扩大为主视觉区域，维持两路十二格与六个部署格 |
| 路面 | 从 E104 合成板裁取路面纹理，替代纯色格板 |
| 主将 | 改为左右全高固定侧槽，中心保持在两路中线外侧 |
| HUD | 压缩为顶部金属色控制条，投降保留在顶部 |
| 受击 | 改为点击敌方主将触发，不再显示调试按钮 |
| 手牌 | 上移至战场下缘，接入 U001、U002、U004、U008 正式卡面 |
| 选牌 | 增加抬升与金色描边反馈 |
| 单位 | 清除无正式素材的下路图形占位，只保留 U002、U008 姿势预览 |
| 资源 | 手牌改用 256×384 WebP，主将改用 768×1152 WebP |

## 四、未通过项

1. C009、C001 缺少透明分层立绘和 Spine 数据，当前侧槽仍能看出卡面边界。
2. U002、U008 姿势板没有透明通道。运行时去底材质曾导致单位完全消失并降低帧率，已撤回；当前只保留半透明预览。
3. E104 没有六张独立视差层，路面裁切存在纵向拉伸，无法验收视差和遮挡。
4. HUD、卡框和主将装饰缺少正式九宫格切片，只能验证布局，不能验收最终材质。
5. 二十四单位压力场景仍是程序化批次占位，且无头样本低于性能门槛。

## 五、下一闸门

下一批必须先交付透明 U002、U008 战斗单位与 C009、C001 分层骨骼，再继续做动画和性能。正式素材到位前，不再通过 Shader 或卡面裁切模拟最终战斗单位。
