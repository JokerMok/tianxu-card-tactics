# 首关测试方案
版本：1.0　日期：2026-09-06　角色：单人玩家及独立测试者

所有自动化场景使用独立存储夹具，不读写用户真实存档。新增测试先观察预期失败，再实施；浏览器场景必须操作 Cocos 正式入口。

|编号/需求|层级与前置|步骤|期望与自动化|
|---|---|---|---|
|TEST-401 / REQ-401|单元/现有配置与固定种子|分别从 CLI 与注入配置的核心执行同一命令序列|状态、事件、哈希一致；执行 Node 对照与浏览器依赖扫描|
|TEST-402 / REQ-401,402|单元/两套合法配置|交错创建两局；改变卡组、关卡输入|每局只消费各自快照，不串配置；空配置、未知 ID 拒绝启动|
|TEST-403 / REQ-402,404|集成/首关准备完成|选牌、部署、施法、结束回合，观察敌方行动|合法动作改变真实状态；界面同步，规则产生终局|
|TEST-404 / REQ-402|单元/活动会话|未准备出牌、越界部署、占格、非活动方出牌、重复命令、终局后出牌|错误被拒绝，状态和资源不变；断言前后快照|
|TEST-405 / REQ-403|事务/内存存储与故障注入|进入、重复进入、结算、重复结算；各持久化位置模拟写入失败|只扣一次，只奖一次；失败不出现半提交，重试与重载一致|
|TEST-406 / REQ-403,405|集成/已保存活动局|刷新并重放；在终局保存前后刷新；再进入新局|牌序、血量、回合、奖励一致，新局无旧回调；配置版本不匹配给出恢复阻塞|
|TEST-407 / REQ-403|迁移/旧存档、损坏或未来版本记录|加载、尝试恢复、模拟空间不足|旧数据保留；有可理解错误提示；不静默重置、不覆盖原记录|
|TEST-408 / REQ-404|安全/正式构建|点击敌方主将；检查公开调试入口；传入伪造胜利布尔值|不能改血或领奖；只接受活动会话产生的终局凭据；不承诺本地防作弊|
|TEST-409 / REQ-405|浏览器/Creator 3.8.8 构建|从主城完成胜利、失败、退出与连续两局；刷新；观察菜单与战场数值|无控制台未处理错误，资源/进度/卡组与核心一致；保存操作记录、截图与状态对照证据|
|TEST-410 / REQ-401,405|回归/相同基线|运行 Runner、类型、Golden、parity、配置、React 测试与构建|旧规则无回归；失败区分既有故障与新增缺陷|

验证脚本由各任务创建并直接运行，不引用不存在的 npm script。TEST-409 的自动化浏览器可驱动合法 UI，但不得用测试扣血、伪造胜利、直接改核心状态代替游玩。
