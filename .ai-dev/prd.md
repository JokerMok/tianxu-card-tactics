# 首关真实战斗接入需求
版本：1.0　日期：2026-09-06　状态：待批准

## 问题与目标用户
单人战术卡牌玩家需要通过部署与施法影响胜负，并保留战后进度。当前 Cocos 入口使用演示扣血，已有规则与奖励服务未形成玩家可验证的流程。

## 目标与用户故事
玩家从主城选择 L01，使用合法卡组完成战斗，查看结果与奖励，返回后再次进入；刷新后不丢失已确认的进度，不重复扣费或领奖。
本次只验收首关流程，不代表全部产品完成。

## 需求与验收
|编号|优先级|需求及验收|
|---|---|---|
|REQ-401|P0|将 Runner 的文件读取与规则执行分离。浏览器依赖图无 node:fs、node:path、node:url；原有 CLI、种子、事件及哈希对照保持一致。|
|REQ-402|P0|每局拥有唯一编号、配置版本、关卡、卡组快照、种子、命令记录与生命周期。非法卡组、目标、时序不得改状态或扣资源。首关仅消费校验后的真实配置，不接受调用者伪造数值。|
|REQ-403|P0|扣费、进行中记录和终局奖励采用持久化事务。重复提交同局结果不重复发奖；失败或主动退出不发胜利奖励。写入失败保持原状态并允许重试。刷新按已保存命令重放，不重复扣费；配置不匹配时暂停并提示，不清空旧存档。|
|REQ-404|P0|Cocos 正式入口接入会话，手牌、部署格、血量、回合、结果均由真实状态驱动。敌方按规则行动；取消直接点主将扣血和外部布尔胜利接口。表现完成与否不决定胜负。|
|REQ-405|P0|首关可完成胜利、失败、退出、重入与刷新恢复。浏览器实玩及独立审查通过；不能仅靠静态检查、测试全局变量或截图数量验收。|

## 边界
不迁移引擎，不改数值平衡，不批量制作美术，不扩展十二关、PVE、商城、账号或支付。不删除现有代码、存档、未跟踪文件、旧 worktree；不操作当前编辑器窗口，不推送或发布。
现有存档保留原键；新记录使用独立版本键，并保留迁移前副本。卡牌 ID 由真实配置校验，禁止按数组位置猜测映射。
P1/P2 产品功能不在本次实施范围；实施中发现的 P0/P1/P2 缺陷均阻止验收。

## 技术与安全约束
保留 Creator 3.8.8 与现有纯规则，Node CLI 作为配置读取包装层。复用 BattleSessionController 与 BattleResultTransactionService 的可用机制，不能另造一套冲突状态。
这是本机单人存档一致性方案，不承诺防止玩家修改本地存档；不得上传私有项目、凭据或数据。
基线测试失败、协议矛盾或必须扩大允许路径时暂停，保留证据，不通过删测或宽放断言处理。

## 未决事项与切断线
实现前核对已有规则的敌方回合编排与合法卡组协议；若需变更玩法规则，退回方案评审。
正式美术、真机性能、长期留存仍未验收，不计入本次完成声明。
