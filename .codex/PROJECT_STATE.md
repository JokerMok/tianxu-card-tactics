## 关键决策
横向战斗以地图内侧向角色为准，不能用正面切片镜像或旋转冒充侧向攻击。旧骨骼只作为技术试验留档；当前六姿势方案是美术与节奏校准样板，未定为最终量产方式。参考《Minion Masters》战场优先与底部手牌、《Master Duel》边缘状态和集中回合控制；视觉材质与卡框以本项目系统页为准，不套用竞品视觉。地图人物按透明像素实际身高与脚底校准，手牌 146×219 的 UI 比例与地图人物无关。两行战线都须实兵展示；场景下缘不得放置遮挡人物、主将或手牌的高耸前景物。设计稿示意不覆盖真实存档；历练、编队编辑和物品使用仍标未开放。
