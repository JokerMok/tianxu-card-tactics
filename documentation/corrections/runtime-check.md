## 实机检查发现并修正

- 同名 `ajks_1` 未选来源导致开战按钮抛错；明确选择 `ui_step1.swf#177`。
- 原布局文本默认 autoSize、字体尺寸关系及 Sprite 自定义尺寸顺序影响界面；按源关系修正。
- 禁用地图地标吞掉已解锁区域点击；禁用控件不注册触摸。
- Creator 将迭代器 spread 编译为数组拼接，造成卡牌筛选为空/单位遮挡排序错误；用 Array.from 并检查实际构建产物。
- 卡组跨栏释放触发 TOUCH_CANCEL，补正常落点处理；关闭保存等服务回读确认，失败保留草稿。
- 原模型 anchor/wanchor 在缩放前定位，actor body/weapon 共用 renderer；窗口预览按原 AutoupdateAssertBackground 的尺寸语义，而非额外缩小。
- 角色等级、经验、生命值落回原数值槽；不存在的暴击、士兵百分比模型用“—”。
- 强化底板、空装备槽沿用旧背包物品、邮件按钮被背景遮挡、商城图标空白和静态99占位均已定向修正。
- 新战斗从轮询出现时自动进入，房间继续按钮直接恢复战斗；新增 PVE 的 AI 首轮从独立 entryState 排队，刷新/恢复不重播历史，投影不泄露敌方牌库。
- 宠物入口按 MainToolBarMediator.onPet 改回 PetWnd，不再误用 XML tooltip 路由到邮件；商城本地卡包商品用源类别图，导入器保留来源。
- 房间创建/加入后进入对应房间；人物身份使用真实职业/性别。旧存档缺少gender时按服务端既有男性默认规则兼容；实机法师模型与取消准备已确认。

- PVE首轮独立120帧8.27秒，初始9HP先保持，再按事件显示−1与8HP；托管战斗连续388帧29.69秒已采到结算，最大采样间隔0.126秒。采集工具在结算已出现后到时，逐帧文件完整；该段时间由每帧文件写入时间恢复，视频未补帧。
