# 1—19章主线保留依赖核对

核对日期：2026-10-24。当前分支 `codex/art-samples-pve`，HEAD `dbd5434`；精简PVE实施基线 `554f265`。`554f265..HEAD` 在本次核对的五个运行文件上无差异，因此以下结论适用于当前美术样板分支。本次只做静态链核对，没有启动服务、连接数据库或逐章实玩。

## 结论

没有发现由本阶段暂停模块造成的、可从当前代码与配置确定的1—19章主线断链。

当前强制链为：合法卡组 → 已解锁当前场景 → 图内前置节点已通关 → 达到下一场景等级 → 执行转场解锁下一场景。任务、建筑、声望、装备强化、宠物、多人及扩展PVE不参与这条强制链。

## 逐类前置

| 前置类别 | 当前实际规则与数据 | 暂停范围影响 |
|---|---|---|
| 场景范围 | `stageSceneAllowed` 明确保留数值场景 `1..19`；场景表和 catalog 中19个场景均存在。`scene-compatibility.mjs` 只补建缺失副本场景，没有重建1—19章。 | 无确定断链。扩展场景 `2501/2502/2503/6301` 与困难等副本暂停，不在普通主线链内。 |

| 图内通关节点 | `nodeAccessible` 只读取当前场景解锁、起点、`clearedNodes` 与图边；胜利结算写入 `clearedNodes/clearedTriggers`。对19章图逐一做静态可达闭包后，1—18章各自转场节点均可达，19章没有后续转场。 | 无任务、建筑、声望或暂停玩法条件混入节点可达计算。静态清关数依次为5、8、8、8、9、9、10、10、11、12，11—19章各12个战斗节点；这是图可达性计数，不是逐关实玩结果。 |
