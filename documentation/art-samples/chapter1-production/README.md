## 生产流程与成本

重复制作规范：[production-spec.md](../../../art-source/chapter1-production/production-spec.md)。`batch.json`按modelId声明对象，生成源与候选稿独立保存；`produce-batch.py`拒绝相连主体、统一注册/裁剪、校验无损WebP可见RGB与alpha一致，生成内容摘要清单。`package-batch.py`只打运行引用并可逐文件核对HTTP摘要。没有增加第二播放器或大型资产平台。

成本与逐文件哈希在 `art-source/chapter1-production/costs.json` / `runtime-package.json`，zip在 `.local/art-production/art-runtime-v5.zip`，仅本机。47文件HTTP摘要一致，WebP MIME为image/webp；不包含DB、账号、日志、逆向整库或审阅录像。RGBA不是实测GPU显存；此环境未取得可靠GPU专用内存数值。

原9图集上限按本批实际成本调为19/128MiB明确准入；保留活跃不淘汰、同模型共享与最后引用释放，不全量预载。十九种实际共存不缺帧，按引用加载/释放；ResourceTiming十九项不是重复下载证明，transfer0可能浏览器缓存。观测P95约9.1–9.8ms，包含等待/静止，仅当前本机rAF代理，不能宣称GPU帧时或普遍性能提升。

当前录像未见明显异常消失。反向累计159个首次未呈现采样、334个合法透明采样、148个零血原资源空帧歧义、0个分类为unexpected；采样次数不是毫秒，不把首次未呈现一律称为已证明加载，也不把零血歧义写成正常。详见runtime系列JSON，后续仍需关注旧源死亡分支。
