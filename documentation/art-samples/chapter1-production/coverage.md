# 第一章角色美术覆盖台账

统计日期：2026-10-26。机器可读明细见 [coverage.json](./coverage.json)，下一批 10 个制作对象见 [selected.json](./selected.json)。

## 本轮完成后的覆盖

默认sample现为v5：19个源模型；直接引用12/12均有新资源；随机池与直接引用并集19/127，剩余108个继续使用原资源。另有骨堆、鼠群及已登记召唤链，单列而不混入127。十个新增模型在同一原生Cocos战斗中实际显示、移动与交战；普通账号证据见README。完整动作不等于每个模型都自然掉落或逐技能验收。

同模型回退已接入ArtSkin/RecoveredAnimation，卡2可复用Guard，限定相同scope和精确modelId；不同装备/模型不按名称覆盖。以下v4统计保留为制作前基线，后续表中的“当前v4”均指该基线。

## 制作前口径

本台账覆盖第一章 `main:scene:1` 的实际战斗路径：初始四卡、五个首通卡牌奖励、五个固定敌方英雄，以及当前 `minLevel=1` 的敌方随机牌组池。随机池来自 `ServerContent.enemyDeck` 的真实筛选条件，不等同于普通掉落池。

按恢复资源中的稳定 `modelId` 去重后，直接引用与随机池的并集共有 **127 个模型**：

- 随机牌组池有 129 张可抽卡牌、119 个模型；
- 初始卡、首通奖励和固定敌人共有 12 个模型，其中 4 个也在随机池；
- v4 已有 9 个模型的制作成品，按模型口径还缺 118 个。

这里的“已有 9 个模型”表示同一恢复模型已有可用成品，并不表示该模型的全部怪物 ID 都会自动命中成品。制作前v4解析器先按 `main:monster:<id>` 精确查清单；只共享 `modelId`、但未列入 v4 清单的 ID，仍会走原始恢复动画。第一章相关 ID 中，当前只有 10 个怪物 ID 精确命中 v4。

Bone Heap 1169、1187、1380 的完整来源链为 `1550 → 1513 → 2701/3301` 和 `1550 → 8601`：前一支禁止移动和攻击，后一支在一回合后重组。效果 8601 没有给出目标怪物 ID；当前实现按同种族目录顺序选择第一个不同怪物，三个骨堆都会变为 Zombie Guard 1001，而且不会清除“不能移动/攻击”标记，也不会补挂 1001 的能力。因此这条路径只能记为“已执行但与原描述不一致”，不能据此把 1001 当作原版确定的骷髅重组目标。

Blaze Adept 的四个原配置目标分别是 Flame Whelp 12001、Flame Dragon 12015、Flame Dragonkin 12032 和 Kaelithus 12022。当前 `applyStaticEffects` 会读取 Type 50 的子效果 11701，但 `activeEffectRows` 只递归展开 Type 15，后续回合逻辑看不到 Type 117，所以四种火龙没有从这条路径实际召唤。

本范围内还出现效果 7702。原描述要求 Chantress 211、Archangel Luo 21247 和 Zero BB 21451 的击杀阻止目标复活、还魂及 Type 85 骨堆召唤；当前代码只给攻击者设置穿透和 `eraseKills`，后续击杀流程没有读取 `eraseKills`，所以阻断规则尚未真正执行。没有任何本范围根效果或组合子效果到达 Type 113、155、166、170、196、405、409 或孵化标记 7703；这些通用分支不列为第一章已知依赖。

## 边界

战斗内还可能由卡牌效果、死亡、复活、陷阱、回合触发、孵化和地形产生二次召唤。这些分支依赖实际抽牌和局面，本轮没有穷举运行，因此不计入 127 个模型的分母，也不声称第一章所有潜在召唤都已覆盖。

本台账证明的是恢复数据、运行时筛选、效果依赖和美术清单之间的对应关系。本批10个对象已制作成v5并完成原生混合运行QA；这里不代表最终视觉确认、生产部署、完整第一章流程或全部美术已经验收。
