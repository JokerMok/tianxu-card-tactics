## 图集与播放器

沿用一个`SampleUnitAnimation`及共享图集库，不复制兵种播放器。位移仍由现有Speed/距离决定，攻击通过既有cue回调推进HP与事件队列。图集里的角色不改变逻辑站位。

| 规格 | 侍从 | 枪骑兵 |
|---|---|---|
| 图集 | 1536×1280；6列×5行，单格256 | 1920×1600；6列×5行，单格320 |
| 显示容器 | 170×170 | 200×200 |
| 固定脚底/挂点 | `[128,220]` / `[128,178]` | `[160,280]` / `[165,196]` |

| 局部origin | `[0,-32]`，沿用原脚底接入 | `[0,-32]`，不改变格子脚底 |
| 待机 | 0起6姿态、8fps循环 | 同左 |
| 移动 | 6起6姿态、13⅓fps循环 | 6起6姿态、16⅔fps循环；马腿与骑手实际姿态变化 |
| 攻击 | 12起6姿态、12fps；命中0.25s、结束0.5s | 12起6姿态、8fps；命中0.375s、结束0.75s |

没有给这两个单位配置通用盾挡反应；0伤害只按真实事件显示既有反馈。生成的是绘制姿态，非独立骨骼/物理模拟；马与骑手画在同一动作帧中，不是步兵整图平移。两方向围绕固定脚底镜像，挂点同步；没有独立背面视图，侍从盾剑会交换屏幕侧。当前正侧视图的枪尖和攻击方向正确；这不代表任意机位、多挂件都已支持。
