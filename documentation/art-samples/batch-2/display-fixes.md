# 战斗显示定向修复

日期：2026-10-25  
范围：`codex/art-samples-pve` 本机表现层；不涉及权威规则、伤害、队列排序、战场站位、热区、卡组逻辑或素材替换。

## 死亡显示生命周期

`revision-2/evidence/guard-block-fall.mp4` 的 3.25—3.75 秒可见卫兵图像淡出后，`1 / 0` 仍单独保留。原因是死亡透明度原本只施加在 `RecoveredAnimation.node` 或备用姿态副本上，而生命、攻击和名称标签挂在稳定单位容器 `display.node`；该容器按原客户端兼容时序继续注册满 2 秒才释放。

修复后仍先完整播放原生死亡动作；原生动作完成后（没有原生死亡动作时立即）对稳定 `unitId` 对应的整个 `display.node` 做 0.6 秒淡出，所有可视子对象共享透明度和清理时点。2 秒实体注册时序保留，不提前删除。释放同时校验 Map 中的对象身份和动画代际，迟到完成回调不会删除同 ID 的新显示对象。名称和数值仍固定在单位逻辑容器中，不随逐帧图像边界移动。

## 顶部战斗 HUD

回合和行动者移到设计坐标 `y=292`、高 16 的顶部安全带（对应 600 高设计画布顶部 0—16），字号固定为12、行高14；实机发现较高骑兵仍接近提示后，将单位名称固定上限设为Cocos y273（名称框顶部至少设计y18），与HUD保留2设计像素以上间隔，不改脚底或站位。行动者名称最多显示 10 个 Unicode 字符，超出用省略号截断，不再用缩小字号适配。处理队列期间保留当前回合和行动者，不持续显示“战斗进行中”；现有卡牌与回合按钮的禁用态继续承担不可操作反馈。

## 定向检查

`node --test tools/art-samples/test-battle-display-lifecycle.mjs` 覆盖：整实体淡出、同 ID 替换后的迟到释放隔离、顶部安全带边界、固定字号和长名称截断。测试执行当前Presenter的实际方法，仅Cocos节点/时钟用适配器。真实Creator构建已完成，混合战斗48秒连续片段与24—28秒卫兵死亡连续帧见README；图像和攻血一起消失，上排名称与HUD分离。逻辑测试与实机记录分别保留，不互相替代。
