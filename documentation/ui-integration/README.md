## 本机入口

[进入正式游戏](http://127.0.0.1:7410/?client=integration)。从主城底部“卡牌”进入，也可从“图鉴”进入。7410 运行正式 Cocos 构建与原有权威服务，使用隔离测试数据库；不是 7405 的独立预览。当前浏览器已保留测试角色登录。

在项目根目录启动同一隔离存档：

```sh
TIANXU_PORT=7410 TIANXU_DATABASE="$PWD/.local/ui-integration/acceptance.sqlite" npm start
```

默认 `npm start` 仍在 7400 使用原个人数据库；本轮没有以个人存档做测试。隔离账号凭据和 SQLite 只留在 `.local/ui-integration/`，不纳入提交或审阅资料。已有本机素材继续复用。

## 接入内容

复用独立 A 预览的书本、原卡图/图框、无字派生素材、滚动和虚拟槽位实现，整合进唯一正式 `CardDeckWindow`。预览工程不是正式运行依赖。卡组、持有/图鉴和详情独立滚动；数量、筛选、保存固定。每栏 15 个槽位，纹理按需加载，闲置缓存目标 56 项。中文正文换行并滚动，不依靠无限缩字。

正式保存调用原 `/api/act` 的 `deck.save`，以服务器确认的卡组更新保存基线。容量、持有量、职业、数量规则仍由原服务校验。保存期间的新修改不被旧响应标为已保存；不确定失败重试沿用原请求标识和原提交内容。轮询、切角色和离开窗口分别处理草稿，失败不静默关闭。

## 中文范围与剩余项

当前 main 中有效且关联到兵种/技能的卡牌共 **7,032 条**、**1,852 个不同原名**；废弃、Abandoned 和其他版本数据不计入。卡名：113 条有中文字段或上下文依据，6,919 条为候选；没有缺少展示名的活动卡牌。多数候选名称未逐项人工审校，不能称全量官方中文恢复。

关联效果 2,804 条：2 条原中文、2,792 条候选、10 条源说明缺失。技能卡说明 750 条：103 条原中文、636 条候选、11 条缺失；其中 3 条从关联 Skill.Des 补回。缺失内容显示“原资料未提供完整技能说明，待核对”，不根据卡名编造效果。候选、原名、原文、稳定 ID 和源行分别保留。卡库、详情、战斗手牌、奖励及相关窗口共用这份映射。

## 结论边界

本轮正式卡牌管理及真实保存已接入并完成下列定向验收。没有重新验证整款游戏的全部章节、多人模式、设备或技能机制；不把 PVE 一场胜利当作整款复原完成。原版材质、原图和已有战斗队列继续保留。竖向滚动、固定详情和显式保存是用户授权的体验优化，不声称已证明是原版行为。

既有战斗结算材质仍烘焙有 Victory、Turns、Time，地图专名及部分战斗状态按钮仍有英文；本轮没有重做这些美术。卡牌中文候选和源文歧义仍需定稿。物理触控板、触屏真机和长时间 GPU 压力没有单独验收。用户实际体验与分支合并、发布需另行确认。
