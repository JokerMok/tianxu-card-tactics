## 需要产品或规则源确认的歧义

- `main:card:50610`（黑暗咆哮）：恢复文本自称“单体辅助技能”，效果目标却是“所有敌方士兵”。因其是现存中文，当前逐字保留。
- `Meteor Storm` 有一组英文效果是“将墓地中随机2张生物卡牌返回手牌”，与名称“流星风暴”语义不一致。当前按效果原文翻译，没有改成伤害效果。
- `Crazy Bomb` 的英文源明确写作“Unknown effect”，随后列出五种可能结果。当前完整保留这些分支，不把任一分支断言为确定效果。
- `Paralysis` 只写“有概率麻痹”，没有给出概率数值。当前没有补造百分比。
- `Hermes Wings` 与 `Hermes' Wings` 是两个不同的原始拼写，候选中文都译为“赫尔墨斯之翼”；如 UI 需要区分，应由规则或资产证据决定，而不是凭拼写补差异。
- 若干恢复中文含明显疑似源数据笔误或不完整措辞，例如 `Demonic Spawn` 的“场地存在1合”和 `Hell's Hands` 的“敌方士兵生命不能移动”。为满足原文保留要求，当前没有静默修订。
- `Petrify`、`Dispel`、`Protect` 等名称存在多版效果文本；各条记录按自身 ID 和 `originalText` 独立保存，不能仅按名称合并覆盖。

## 状态含义

- `recovered`：直接来自 `census.raw.Des` 的完整中文，逐字保留。
- `candidate`：根据 `census.raw.Des` 的全英文或英中混合源生成的忠实中文候选。
- `missing`：源效果字段不是文本，当前没有足够证据恢复效果。
- `runtime-description`：原文缺失，但恢复参数与当前运行规则足以描述本版本的实际行为；不主张是官方文案。
- `unsupported`：可确认配置类型，但关键服务端规则未恢复；运行时不提供合法出牌，也不会扣牌后空放。

生成脚本会在发现未映射名称、未翻译英文效果或英中混合描述仍有成段英文时失败，以免新增卡牌静默回退为英文或占位文本。公式变量 `N` 可保留。
