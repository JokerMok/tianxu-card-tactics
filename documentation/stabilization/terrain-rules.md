# 13 张持续地形牌：本版本权威规则

本实现让 Cocos 客户端、AI 与服务端共用 `BattleKernel` 的同一条确定性规则。规则读取技能、效果参数，并使用从 `topography.xml` 提取、由原表测试校验的七条绑定，不执行名称或说明文字。以下属于本版本对原服务端缺失部分的明确约定；静态恢复资料不能证明这些约定与原服逐项相同。

## 数据与状态

- 支持技能：50731–50734、50741–50744、50806–50809、50903。
- `BattleState.version` 保持 1；新增可选 `terrains`，因此旧存档缺少该字段时仍可继续。新战斗写入空数组。
- 每块地形保存 ID、技能/地形 ID、拥有者、队伍、格子、剩余玩家回合数、创建回合与当前占用者。`remainingTurns: null` 表示持续到战斗结束。
- 新地形覆盖旧地形的重叠格；旧地形未重叠格继续存在。每个格子最多属于一块地形，不叠加相同或不同地形效果。
- `terrain-add`、`terrain-update`、`terrain-remove` 事件均带当时的完整地形快照和 `terrainId`。占用或剩余回合变化先发事件，再结算相关伤害；战斗结束清除全部地形并发 remove。

## 放置

- ServerClass 19 使用 `CureValue` 作为不同格子的数量上限（候选格不足时取全部候选格），范围为配置的 `StartX..EndX` 和所有战场行。玩家选择的有效锚点必定包含，其余格子用战斗 RNG 无放回抽取，因此重放与服务端结果一致。
- 0 队按配置绝对列放置；1 队以 12 列战场镜像。合法锚点只有配置范围内的内场格，不带单位 `targetId`。
- 50903 的 0 队合法锚列为 5，覆盖列 5–9 的所有行；1 队合法锚列为 6，覆盖列 2–6 的所有行。锚点的行可选，但覆盖始终为上述五列全行。

## 触发与时限

- 放置到已有单位脚下算一次进入。以后召唤、交换、拉取、击退、撤退、命中后撤和正常移动每进入一个地形格都结算一次；同一块地形内从一格走到另一格也再次触发。
- 每名玩家结束回合时，其当前所有存活单位各结算一次停留效果，包括该玩家本回合新召唤的单位。地形刷新本身不会重复触发进入或停留。
- 停留结算后，孵化地形在拥有者回合结束时对每个空地形格尝试一次召唤；占用格直接跳过，不累计到以后。随后所有有时限地形减 1。八回合表示八个玩家回合，不是八轮双方回合。
- 地形拥有者死亡不会单独移除地形；定时地形继续到期，永久地形继续到战斗结束。若战斗已结算则统一清除。

## 逐类效果

- 50731–50734 连接 50704：持续 8 个玩家回合，停留造成 5 点火焰伤害。
- 50741–50744 连接 50705：持续 8 个玩家回合，停留造成 7 点火焰伤害。
- 50806 连接 40503：3 格、持续 1 个玩家回合；每个空格用同一累计随机表选择 9091（`roll < 90`）或 9093（`roll < 100`）。
- 50807 连接 40504：规则同上，召唤 9092 或 9094。
- 50808 连接 40056：3 格、永久；进入与停留各造成 3 点火焰伤害。
- 50809 连接 40057：6 格、永久；进入与停留各造成 5 点火焰伤害。技能说明中的“进入 3”与效果/地形配置冲突，本版本以配置为准。
- 50903 连接 40801：永久；双方单位进入时移除全部正面 `UnitStatus`（含光环状态），在地形内不能获得新的正面状态。离开后可以再次获得，但已移除的状态不会自动恢复。原地形文字的“任意玩家单位”与效果说明的“敌方”冲突，本版本采用原地形文字，双方一致生效。

伤害走现有伤害、死亡和召唤反应路径。单位在进入途中死亡时立即停止继续移动与攻击。孵化召唤也走现有 token 召唤、召唤反应与死亡路径。

## 定向验证范围

定向内核用例覆盖 13 张牌的配置绑定、合法锚点、真实进入/停留伤害、逐格移动死亡、孵化概率候选与到期、正面状态移除/阻止、覆盖替换、事件顺序、旧状态兼容和 JSON 往返。该结果证明当前 `BattleKernel` 的本地权威行为，不代表原版服务端运行对照、完整 Cocos 展示或远端生产验收。
