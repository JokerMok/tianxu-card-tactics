- 完整遍历 `card-names.json` 的 1,852 个不同原名，按物种、职业/兵种、塔罗逆位、系列后缀、Unicode 变体、拉丁字母残留与标点做确定性检查，并对命中的明显语义问题直接复核。共修正 62 个候选名；`status`、`source`、原名键和稳定 ID 均未改动。
- 23 个 `Ogre` 统一为“食人魔”，7 个 `Troll` 保持“巨魔”，避免两个独立种族继续混称。同步修正猫人刺客、勇士、军团战士、逆位牌名及“阿兹拉耳之触”等成组问题。
- `GameText.presentationName` 覆盖正式 main 数据实际发出的章节、节点与副本名称：259 个不同节点源名中 235 个含英文，61 个场景标题中 29 个含英文，65 个副本名全部含英文；复核后未留下未映射的英文项。映射只作用于展示，不改服务端原名或 ID，也没有把 media/旧版本名称混入当前范围。
- 战斗“手动/自动”改用同一套原版按钮材质加运行时中文文字，不再显示烘焙的 `Manual` / `Auto` 小图。
- 胜负结算使用两张独立无字派生素材，并由运行时绘制“战斗胜利/战斗失败”和“回合数”。没有用中文遮住英文，也没有修改恢复原件。

## 世界地图烘焙文字

- 两张世界地图继续使用原有 `MAP_ONE` / `MAP_TWO` 坐标、1–19 区热区、解锁禁用与翻页条件。原 `worldmap-region-1..19` 的英文区域名和地形位于同一位图，没有可单独关闭的文字层，因此为每区生成独立透明无字派生；运行时绘制“第 N 区”和中文区域名。派生保持原画布尺寸与原 alpha 逐字节一致，AI 补绘只进入 provenance 登记的 `textNeighborhood` 及 1.5 px 羽化边界。
- 原 `btditu` 只有烘焙 `MAP` 字样，窗口现直接在原窗口框的无字标题位绘制“世界地图”。原 `scene-trigger-go` 只有烘焙 `GO`，场景跳转改为复用同源无字 `ajda_1` 按钮材质并绘制“前往”；没有用色块遮字。
- 19 张场景底图右上角均含烘焙 `Chapter`。检查区域统一为源图左上坐标 `[590, 0, 150, 70]`；无字羊皮卷中间件来自第 15 章该区域的内置图像编辑，最终替换矩形为 `[598, 0, 138, 56]`。每张底图先完成替换并扁平导出为独立 `740×441` 全图派生，运行时只加载 `scene-background-N-textless.jpg`，不会把无字卷轴叠到仍显示的英文原图上。中文“第 N 章”和区域名随后由 Cocos 单独绘制。
- 中文区域名按原任务表和 SWF 区域顺序固定映射，服务端 scene ID、原名、节点、跳转和业务状态均未改。素材源路径、原件与派生 SHA-256、SWF character ID、文字邻域和章节替换矩形均见 `cocos-client/assets/resources/ui-revision-a/provenance.json`。
