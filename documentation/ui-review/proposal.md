## 滚动与拖放

- 三个滚动区域独立处理滚轮/触控板，显示真实滚动条；不足一屏时隐藏滚动条，偏移归零，不拖动整个窗口。
- 标题、筛选、数量和保存固定。每个模式/筛选保存自己的偏移；增删卡和切换模式保留草稿、选中卡及合理的滚动位置。
- 两个卡牌区域各复用15个槽位，仅绑定可见区及缓冲行。纹理按需加载、引用计数释放，闲置纹理采用56项缓存目标；正在被可见节点引用的纹理不强行释放。
- 点击卡面固定详情；加减按钮执行明确操作。滚轮只滚动，不会加减牌。快速竖向指针移动按滚动处理；横向拖动或停留后拖动进入卡牌拖放。
- 拖放使用独立显示层和合法目标框。加入/移除必须释放在另一栏的完整内容矩形内；标题、筛选、边框、窗口外或原栏释放均取消。不能只比较横坐标。
- 可见项复用不更换手势监听的所有者；固定槽位持续处理移动/结束事件，防止滚动后换卡丢失拖放事件。窗口失焦、取消及Esc清理拖影。
- 详情不会因鼠标离开卡片而关闭；指针进入说明区可继续滚动。重复查看同一卡牌保持阅读位置，切换后也记录各自详情偏移。

## 数量与反馈

普通/悬停/选中、可用数量、已全部加入、尚未持有分别显示。卡牌可查看与能否加入分开；不可加入时在书页底部给出中文原因。选中金边不代替数量状态，错误用叹号与文字，不只换颜色。

左栏固定未修改、未保存、保存中、已保存、保存失败。保存中对应真实请求，ACK确认后更新提交版本的保存基线；期间继续修改仍为未保存。失败保留草稿、详情和偏移；未知结果重试沿用同一请求ID与原提交内容。后台轮询不覆盖未保存草稿；角色各有会话。关闭时继续编辑/保存后关闭/放弃修改，不确定请求先确认结果，不能静默丢失。

容量、持有、职业及组牌限制由原后端校验，UI从真实state读容量，不再使用预览固定容量与模拟延迟。测试夹具与个人进度隔离。
