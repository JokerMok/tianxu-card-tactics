# A修订版：中文展示＋竖向滚动＋干净组件化界面

本方案替代上一轮A/B规格。正式玩家界面以中文为展示标准，卡组、持有/图鉴、长说明分别竖向滚动。原版保真精修仍是视觉方向；固定9张分页、保留英文名作正式基准、截图叠层预览的旧要求全部失效。

本轮已经制作**独立 Cocos 3.8.8 预览**，不是旧截图上的叠层，也不是正式游戏已合入。入口：<http://127.0.0.1:7405/?fresh=1>。保存、持有量、容量样本与失败均为显式模拟状态，不调用游戏服务、不读取账号或个人数据库。战斗手牌、相机、模型、动画和规则不在修改范围。

## 页面与文字角色

设计坐标1200×600。书本(178,57,792,532)保留双页羊皮纸/金属框方向。卡组视口(212,145,330,350)，右侧持有/图鉴视口(585,145,330,350)，各3列；行数按内容增加，不分页。固定详情面板(978,57,212,532)，说明视口(990,320,180,252)。左侧(10,57,150,532)固定数量、草稿和保存操作。

卡图85×116，沿用原卡框；名称13/18、最多两行，长称谓在“·”前按语义断行，避免单字孤行。详情卡名16/21、中文技能正文14/19，原背景文字13/18，数量12/17，按钮13/18。纸面深墨色，无描边；深底用浅米色/金色，数值角标独立。正文不 SHRINK，内容超过高度独立滚动，条件/对象/次数/数值不会因为排版而删掉。

每段字只有一个来源。书本的“Current Deck / My cards”制作成独立无字派生背景；按钮使用原无字按钮材质，文字、卡图、卡框、数量、按钮、滚动条分别是节点。侧栏框体只使用源窗口不含文字的顶部/边框区域，经SpriteFrame裁取及九宫格显示；不绘制原图下部Deck Name/Deck Power区域，不用色块遮字。技能卡的空攻击/生命值不输出null。派生素材单独保存，不覆盖原件。

## 中文内容

本轮预览覆盖183条真实卡牌记录、32个不同兵种效果，以及技能卡“斩击”“黑暗咆哮”。卡名、技能名、分类、种族/职业、准备值、说明、按钮和提示均为中文。

优先复用同条资料中的中文名称线索和中文说明。例如卫兵/哨卫/侍从来自原BGDes，黑暗咆哮的卡名和说明来自原字段。只有英文的项目制作中文候选，并标为候选译名/译文；不冒充官方中文恢复。原名、稳定ID、源行、中文、来源状态分别保存在 [内容映射](revision-a/content-mapping.json)，具体范围与待确认见 [本地化说明](revision-a/localization.md)。未覆盖的其余卡牌不自动用占位名混入当前图鉴。

准备值始终是准备值，不改称费用。效果保留触发条件、目标、概率、次数、持续回合及原数值。中文“圣光/复活/灵魂绑定/骷髅”等术语仍属于候选翻译体系，正式入库前需要术语确认。展示本地化不修改ID、查表关系、原数据或规则。

## 滚动与拖放

- 三个滚动区域独立处理滚轮/触控板，显示真实滚动条；不足一屏时隐藏滚动条，偏移归零，不拖动整个窗口。
- 标题、筛选、数量和保存固定。每个模式/筛选保存自己的偏移；增删卡和切换模式保留草稿、选中卡及合理的滚动位置。
- 两个卡牌区域各复用15个槽位，仅绑定可见区及缓冲行。纹理按需加载、引用计数释放，闲置纹理采用56项缓存目标；正在被可见节点引用的纹理不强行释放。
- 点击卡面固定详情；加减按钮执行明确操作。滚轮只滚动，不会加减牌。快速竖向指针移动按滚动处理；横向拖动或停留后拖动进入卡牌拖放。
- 拖放使用独立显示层和合法目标框。加入/移除必须释放在另一栏的完整内容矩形内；标题、筛选、边框、窗口外或原栏释放均取消。不能只比较横坐标。
- 可见项复用不更换手势监听的所有者；固定槽位持续处理移动/结束事件，防止滚动后换卡丢失拖放事件。窗口失焦、取消及Esc清理拖影。
- 详情不会因鼠标离开卡片而关闭；指针进入说明区可继续滚动。重复查看同一卡牌保持阅读位置，切换后也记录各自详情偏移。

## 数量与反馈

普通/悬停/选中、可用数量、已全部加入、尚未持有分别显示。卡牌可查看与能否加入分开；不可加入时在书页底部给出中文原因。选中金边不代替数量状态，错误用叹号与文字，不只换颜色。

左栏固定“已保存/未保存/保存中/保存失败”，保存失败保留草稿并允许重试。保存模拟延迟1秒，显式开关显示“失败模拟：开/关”；只有模拟确认后才显示已保存。保存写入独立预览的本地存储键，绝不写正式账号/SQLite。这些状态是交互验证，不是服务端事务验证。

“滚动样本”加载24张真实卡牌、模拟容量30，用来检查左栏滚动；“还原5张”回到与修订前相同的5张卡组。样本容量不是新游戏规则或原版行为证据。
