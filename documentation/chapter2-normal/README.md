## 修复的两个实际缺口

1. **章节任务无法从正常任务窗口领取。** 服务端源任务102已就绪，正式窗口却只收到三个基础任务。`player-ui.mjs:mainlineTaskCards`把已解锁章节的现有源任务投影到原任务窗口契约，`service.view`合并输出；不新建领奖逻辑。保留原任务ID、条件、奖励、已领取标记和阶段限制，事件任务及未解锁章节不进入这份列表。奖励摘要明确显示经验与允许发放的附件，原领取按钮和反馈继续使用。

任务窗口实际领取源任务102：500银币、100经验、装备10203×1，角色从6级/6经验达到7级/46经验，银币1140。相同成功请求重试回放原回执；新请求再次领取同一任务返回400“任务未完成或已领取”，资产不变。见 [task-claim.json](evidence/task-claim.json)、[任务已领取](evidence/chapter-task-claimed.png)。装备仍在背包，本轮未宣称完成其穿戴验收。
