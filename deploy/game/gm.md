# 玩家注册与 GM 管理

当前版本取消邀请门禁：玩家直接访问游戏地址注册、登录、建角；游戏 Bearer 身份校验保留。旧 `/beta/*` 跳转首页，旧内测 Cookie 被忽略并在首页过期，不清除游戏存储。历史邀请配置保留用于版本回退，当前服务不读取它。

GM 使用 `/gm/`，独立轻量静态网页；`/api/gm/` 复用现有账号和 SQLite。新账号默认 player；权限绑定 accountId。GM Cookie 为 Secure / HttpOnly / SameSite=Strict，写请求验证精确 Origin 与 CSRF，每条接口重新检查角色与权限修订号。无公网管理员初始化接口、默认管理员或默认密码。游戏 Bearer 不能替代 GM 会话。

## 首次指定超级管理员

尚未收到用户明确指定的账号，保持无超级管理员。先正常注册游戏账号，访问 GM 登录页使用同一账号登录：未授权提示会显示本人 accountId。仅服务器终端可将这个明确 ID 提升，命令不会创建账号；重复提升同一超级管理员不产生重复变更。

```sh
ssh tencent-main
cd /srv/apps/tianxu
sudo docker compose -p tianxu --env-file .env -f current/deploy/game/compose.yaml exec -T tianxu \
  node scripts/gm-admin.mjs promote-super \
  --database /var/lib/tianxu/tianxu.sqlite \
  --account-id '替换为本人现有账号完整UUID' \
  --reason '用户明确指定首次超级管理员'
```

账号 ID 不是密码。不要把密码、Cookie 或令牌写入命令、仓库或交付文档。`status` 查询同一指定账号，`revoke` 撤权，`grant-gm` 提供终端恢复路径；所有写操作复用事务与审计，不替换数据库文件。最后一个超级管理员不能降为其他角色。日常授权、撤权和额度调整在后台完成，普通 GM 不能自提权限。撤权或调额将立即注销该账号全部旧 GM 会话，游戏会话不因此改变。

## 发放与范围

按账号/ID/角色搜索并分页，明确选择一个角色，再选择资源、输入**增加数量**与原因。确认页显示目标稳定 ID、资源与当前余额。无角色账号不会自动建角。

- 银币、金币、晶石；当前有效卡牌（与正式卡库相同 activeCard 筛选）。卡牌仅增加持有量，不加入卡组。
- 已有可靠计数/使用规则的八种道具：转职水晶2、改名卡8、性别转换卡9、强化石100–103、宠物精华包1101。稳定 ID 为 `main:item:<数值>`。候选中文适配保留原名与来源，未宣称官方译文。
- 装备、独立实例、过期条目和其他缺少可靠发放规则的物品拒绝，目录不展示，不能借此插入不可用资产。没有任意字段、扣减、全服群发、SQL 或脚本入口。

GM 可分别授权查询玩家、目录、日志及三类资源。默认单次上限：银币10000、金币100、晶石100、卡牌10、物品100；超级管理员硬上限分别1000000、10000、10000、100、1000。GM 额度可设0，仍检查安全整数、当前余额与道具叠放上限。首版没有每日累计额度。

发放读取事务中的最新角色状态，调用现有资产增量路径。资产、成功日志、永久业务回执及普通请求回执在一个事务提交；失败回滚。操作 ID 全局唯一并绑定操作者与完整内容；同 ID 重试仅返回原结果，改内容拒绝。后台 POST 前按账号在 sessionStorage 保存非凭据操作摘要；未知结果和刷新后只查询原操作或按原内容重试，不自动重新生成操作。确认成功或已拒绝后才结束原操作。

卡组保存不能覆盖发放资产；不修改正在进行的战斗快照，不触发充值、购买或通关任务。目标离线也可收到，玩家重新读取状态可见。成功/拒绝日志记录操作者、目标、数量、前后值、原因、服务端时间与结果；权限变更单独记录。GM 日志不对玩家开放，不含密码或令牌。

## 运行、迁移与回退

`gm-v1` 是现有 schema2 的附加表迁移，带 SQL 校验摘要：gm_access、gm_sessions、gm_operations、gm_audit。历史世界 JSON 不改写成测试数据，迁移在既有事务内执行。回执暂不清理；业务防重不依赖普通回执90天保留窗。

生产配置准确 HTTPS `TIANXU_PUBLIC_ORIGIN`。Caddy 覆盖 X-Real-IP，应用只信任 `TIANXU_TRUSTED_PROXY` 指定的实际 socket 地址；不信任任意 X-Forwarded-For。注册/登录、GM 登录、写操作均限速。静态路由仅有运行白名单目录，不提供数据库、日志、备份或配置。

更新前一致性备份；仅更新 tianxu Compose 服务。回退到6098c0a9可读取保留的 schema2 世界及新增附加表，无需回灌旧库，但会恢复邀请门禁并移除 GM 功能。回退前备份当前库，保留上线后进度及 GM 审计表。具体版本、校验和与实际验收见本轮发布记录。
