必要时下列操作只回退本游戏应用，**保留当前数据库及上线后进度**。先创建唯一新备份目录，再停本游戏；本轮gm-v1附加表与6098兼容，不回灌旧库。回退将恢复旧邀请码门禁并关闭GM功能；旧邀请配置保持在私有shared/config，不能当作继续开放注册的版本。

```sh
cd /srv/apps/tianxu
sudo docker compose -p tianxu --env-file .env -f current/deploy/game/compose.yaml exec -T tianxu \
  node scripts/game-data.mjs backup --database /var/lib/tianxu/tianxu.sqlite \
  --output /var/backups/tianxu/替换为唯一新回退前备份目录
sudo docker compose -p tianxu --env-file .env -f current/deploy/game/compose.yaml stop tianxu
sudo cp -p .env .env.public-gm-saved
sudo cp -p .env.previous .env
sudo ln -s releases/beta-20261023-6098c0a9 current.rollback
sudo mv -Tf current.rollback current
sudo docker compose -p tianxu --env-file .env -f current/deploy/game/compose.yaml up -d --no-build
```

本轮无需回退Caddy的X-Real-IP覆盖，旧应用忽略该字段；不得替换共享Caddy配置。迁移、应用包和镜像可追溯，不合并main、不推送。
